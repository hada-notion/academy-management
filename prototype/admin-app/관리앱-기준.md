# 관리 앱 기준

> 지금 기준만 적는다. 바뀐 이력은 `log.md`, 화면별 동작은 `관리앱-화면명세.md`.
> 새로 만들거나 고칠 때: ① 어느 **영역**인지 정한다 → ② 그 영역에 들어갈 수 있는 **부품**만 쓴다 → ③ 부품은 **공통 코드**로 만든다(화면마다 따로 그리지 않음) → ④ 예외가 필요하면 이 문서 "예외" 칸에 한 줄 적고 만든다.
> 대상: PC·태블릿 업무 화면(관리 앱). 손가락으로 쓰는 화면(학부모 리포트·키오스크)은 9장.

## 2. 화면 영역 — 무엇이 어디에 들어가는가
모든 화면은 아래 영역으로만 이루어진다. 영역 밖에 떠다니는 것은 G뿐.

| 영역 | 용도 | 들어가는 것(이것만) | 크기 |
|-|-|-|-|
| **A 머리 줄** | 앱 이동 | A1 메뉴 접기·뒤로·앞으로·앱 이름 / A2 화면 탭 | 높이 44 |
| **B 왼쪽 메뉴** | 화면 고르기 | B1 시작하기 카드 / B2 메뉴(묶음 이름 + 메뉴 줄 + 할 일 배지) | 폭 272(좁으면 아이콘 띠 64) |
| **C 제목 줄** | 지금 보는 것이 무엇인지 | C1 화면 제목 + 개수 또는 날짜·주 이동, 표 편집 표시, 거르기 요약 [풀기] / C2 시즌 칩(시간표·수업만) | 높이 54, 제목 22 |
| **D 위 줄** | 보기 바꾸기·찾기·화면 동작 | D1 전환 탭 / D2 찾기 칸·거르기 칩 / D3 동작 단추(아이콘만) | 높이 56, 부품 32 |
| **E 본문** | 자료 | 캘린더 또는 표 하나 | 머리 줄 40 |
| **F 오른쪽 창** | 고른 것 하나를 보고 고치기. 아무것도 안 골랐으면 할 일 | F1 창 머리 / F2 창 탭 / F3 본문(묶음 → 라벨 → 입력칸) / F4 아래 동작 줄 | 폭 320~600(기본 360), 안쪽 16 |
| **G 떠 있는 것** | 잠깐 쓰고 닫는 것 | 정보 카드 · 드롭다운·고르기 목록 · 달력·시간 · 알림 · 대화상자 · 모드 바 | — |

- 화면을 바꿔도 C·D·E 머리의 선이 같은 자리(54 → 56 → 40).
- C1 제목 옆 순서: 제목 → (기간 이동) → 개수 → 한 줄 요약 → (?) 설명 → [노션](그 화면과 1:1인 노션 페이지를 새 탭으로, 높이 24·12/600) → 표 편집 표시 → 거르기 요약.
- **기간 이동**(C1): 기간으로 나뉘는 화면만. 시간표·수업 = 주(‹ › [이번 주] + 날짜 범위), 수강료·가정통신문·비용·법정 서류(출석부·영수증 원부·현금출납부) = 달(‹ › [이번 달] + "2026.11"). 둥근 단추 32, 지금 기간이면 [이번 주]·[이번 달]이 진한 갈색. 그 화면의 표·생성·전송·서류가 모두 보는 기간 기준. 기간을 거르기 칩으로 만들지 않는다.
- **한 줄 요약**(C1, 13 회색): 그 화면에서 바로 알아야 하는 합계 하나(수강료 = 미납 n건 · 금액, 비용 = 지출 합계). 없으면 비움.

**B2 메뉴 = 노션 메뉴 1~9 순서 그대로**(묶음 이름도 같음)
| 묶음 | 메뉴 |
|-|-|
| 운영 | 일정 · 가정통신문 · 선생님 |
| 수업 | 수업 · 학습 보고서 |
| 학생 | 학생 |
| 학교 | 학교 · 시험 |
| 수강관리 | 시즌 · 클래스 · 수강 · 시간표 |
| 교재관리 | 과목 · 라이브러리 · 진도교재 · 교재비 |
| 재무 | 수강료 · 비용 · 손익 분석 · 법정 서류 |
| 설정 | 학원 정보 · 알림톡 설정 · 관리자 설정 |
| 바로 가기(새 탭) | 키오스크 · 매뉴얼 · 자료실 · 공개 DB |
- 노션에서 여러 페이지인 것을 하나로 합친 곳: 학생(신규문의·학생 목록·학생 현황 → 등록상태 탭), 수업(수업·보강 관리 → [출결\|보강]), 시험(시험·성적 → 창 탭).
- 새 화면을 넣을 때: 노션 메뉴에 있으면 그 묶음·그 이름으로, 표로 보는 자료면 4장 표 부품 정의(열·칸·거르기)만 더한다.
- 설명 글은 화면에 늘어놓지 않고 제목 옆 (?)에. 화면에 남기는 글 = 경고 · 빈 상태 · 값·개수.

## 3. 위 줄(D) 부품
| 부품 | 크기 | 글자·아이콘 | 쓰는 곳 |
|-|-|-|-|
| 전환 탭(여러 칸 중 하나) | 틀 32, 안 단추 26, 모서리 10/8 | 13/600, 아이콘 16 | D1: [시간표\|수업] · [편집\|추가] · [출결\|보강] · 학생 등록상태 · [5\|7] |
| 찾기 칸 | 높이 32 | 13, 돋보기 16, 글자 있으면 지우기 x | D2 |
| 거르기 칩(켜고 끄기) | 높이 32 | 13(켜짐 600) | D2 |
| **아이콘 단추** | **32×32** | 아이콘 18, 이름은 마우스 | D3 모든 동작 |
| **숫자 단추** | 높이 32, 좌우 8 | 아이콘 16 + 숫자 12/700 | D3 [저장 n] · [수업 만들기 n] |
| **묶음 틀** | 높이 32, 안 단추 31×30, 사이 선 | 아이콘 18 | D3 [↰\|↱] · [− 20분 +] |
| 상태 알약 | 32 원 | 아이콘 16 | D3 수업 "이 주 수업 모두 만듦" |

**D3 순서(모든 화면 같음)**: 화면 고유 동작 → [↰ 실행 취소\|↱ 다시 실행] → [↺ 저장 전으로 모두 되돌리기] → [저장 n] → [창].
- 저장은 늘 [창] 바로 앞. [↺]는 고친 것이 있을 때만 켜짐.
- D3 단추는 폭과 상관없이 아이콘만. 글자가 있는 것은 D1·D2뿐.
- 화면 고유 동작: 시간표 [인쇄] [보기 크기] [5\|7] / 수업 [수업 만들기 n] [보기 크기] [5\|7] / 표 화면 = **네 자리 고정**.
- **화면 고유 동작 단추**(노션 버튼이 하던 일: 생성·일괄 전송·가져오기): 네 자리 **왼쪽**에 숫자 단추(흰 바탕, 아이콘 16 + 대상 수)로, 화면마다 최대 2개. 대상이 0이면 꺼짐. 누르면 확인 창(무엇을 몇 건, [취소][만들기·보내기]) → 한 뒤 알림 "Ctrl+Z로 되돌려요". 표 편집 중에는 숨김. 아이콘: 생성 = 더하기 네모, 전송 = 종이비행기, 가져오기 = 달력.
- **표 화면 네 자리**(모든 표 화면·두 모드에서 자리가 같음): 평소 [엑셀] [표 편집] [인쇄] [추가] → 표 편집 중 [열 정리] [완료] [취소] [추가]. [표 편집]과 [완료]는 같은 자리(같은 단추가 켜고 끔). [추가]가 없는 화면·표 편집 중에는 자리를 비우지 않고 **꺼진 단추**로 두고, 이름에 이유를 적는다.

| 뒤로가기 | 다른 목록(할 일)에서 들어온 창은 머리 위에 [‹ 할 일] 단추: 높이 32 · 테두리 · 글 13/700 · 아이콘 16, 왼쪽 맞춤. Esc와 같음 |
| F2 탭 | 높이 40, 14/600, 같은 폭. 첫 탭 = [정보](수업은 [출결]) |
| F3 본문 | 묶음 제목 15/700 + 아이콘 → 라벨 12/600(칸 위) → **입력칸 40**(왼쪽 아이콘 16 + 값 왼쪽 정렬). 묶음 사이 24. 상자 안 상자 금지(같은 것이 반복될 때만 카드) |
| 줄 펼침 | 줄마다 딸린 글(출결 줄의 한마디·메모)은 줄 오른쪽 아이콘 단추 28로 그 줄 아래에 펼침. 한 번에 한 줄, 적어 둔 줄은 아이콘이 진함 |
| 줄마다 숫자 칸 | 학생 줄에 숫자를 이어 넣는 곳(평가 정답, 성적 점수·등수): 칸 폭 64, 오른쪽 맞춤, 계산 값은 줄 끝 44 폭. 값이 바뀌어 다시 그려도 Tab으로 옮겨 간 다음 칸에 커서가 남는다 |
| 기록 카드 | 창 안에서 같은 것이 여러 건일 때(수업 학습기록). 머리 44(구분 알약 + 이름 + 보조 글 + 작성 중 알약 + 펼침 화살표), 접으면 요약 한 줄, 펼치면 입력칸 + 학생 줄 44(이름 + 고르기 단추 또는 점수 칸) + [삭제]. 묶음 제목 오른쪽 [+ 추가]. 한 번에 한 건만 펼침 |
| F4 아래 줄 | 단추 40. 왼쪽 [삭제]·[종료], 오른쪽 [↺ 저장 상태로 되돌리기] [저장 n] |
| 할 일 | 아무것도 안 골랐을 때의 창. 탭마다 숫자, 메뉴 배지와 같은 기준 |

입력칸은 입력칸 모듈, 고르기 목록·카드는 고르기 모듈만 쓴다(`module-input.html` · `module-pick.html` · `module-student.html` · `module-class.html`에서 모양 확인).

## 6. 캘린더(E)
- 요일 머리 40. 블록 = 클래스 색 옅은 바탕 + 왼쪽 띠 4, 이름 13/700 → 시간 → 강사 → 인원(모자라면 아래부터 뺌, 이름은 자르지 않고 두 줄 → 약칭).
- 겹치면 나란히. 고르면 진한 테두리. 작성 중 = 점선. 지금 시각 = 빨간 선(블록 위).
- 끌기: 끄는 블록은 칸 전체 폭 · 놓을 자리 잔상은 실제 배치대로(겹치면 나란히) · 제자리 잔상 · 위아래 끝에서 저절로 스크롤 · 휠을 굴려도 커서를 따라옴 · Ctrl+휠 = 보기 크기 · Esc = 취소.
- 잠긴 것(운영 중 시간표·만든 수업)은 자물쇠를 풀어야 옮김. 잠금과 오른쪽 창은 서로 영향 없음.

## 7. 고치기·저장·되돌리기(모든 화면 같음)
| 일 | 규칙 |
|-|-|
| 고치기 | 고친 순간 "작성 중"(노션에 안 감). 표시 = 줄·카드 노란 띠, 블록 점선, 창 머리 알약, 탭 노란 점 |
| 저장 | 위 [저장 n] = 남은 작성 중 전부(목록 확인 창). 창 [저장 n] = 그 창 것만 |
| 저절로 풀림 | 저장한 값과 다시 같아지면 작성 중이 풀림 |
| 실행 취소 | ↰ Ctrl+Z · ↱ Ctrl+Y, 한 단계씩 |
| 되돌리기 | ↺ = 저장 상태로. 위 줄 = 전부(확인 창, Ctrl+Z로 다시), 창 아래 = 그 클래스·수업·학생. 저장 창 왼쪽 아래에도 [모두 되돌리기] |
| 삭제 | 바로 지우지 않고 "삭제 예정" → [저장] 때. 이어진 것이 있으면 막음 |
| 확인 창 | 되돌릴 수 없거나 여러 건이 함께 바뀔 때만. 처음 커서는 [취소] |
| 여러 건을 다루는 창(저장·생성·전송) | **무엇이·누구에게**를 목록으로 보여 준다(줄 28, 이름 + 회색 보조 글, 8~10줄 넘으면 "외 n건"). 건수만 보여 주지 않는다 |
| 보내기 대상 | 이미 끝난 줄(결제를 마친 수강료 등)은 대상에서 뺀다. 창에 그 규칙을 한 줄로 적는다 |
| 방금 생긴 줄 | [생성]·[추가]·올리기로 생긴 줄 = 왼쪽 초록 띠 + 옅은 초록 바탕(8초) |
| 모아 보는 표의 값 | 다른 화면에서 계산해 오는 표(법정 서류·손익 분석)는 (?)에 값이 어디서 나오는지 적고, 자료가 없으면 0이 아니라 "—"·"자료 없음" |
| 모드 | 평소와 다르게 동작할 때(추가·보강·표 편집) 화면 아래 가운데 모드 바. 들어갈 때 알림은 없음 |

## 8. 말·표기
- 해요체. 막혔을 때만 "~해 주세요".
- 클래스(반 ✕) · 시간표(요일·시간 틀) · 수업(그날 한 번) · 정규·보강·휴강 · 준비 중·운영 중·끝남 · 작성 중 · 삭제 예정.
- 날짜 YYYY.MM.DD, 시각 HH:mm, 범위는 "-".
- 학생 = 이름 + 학교(회색) + 학년 칩.
- 단추 이름: 실행 취소 / 다시 실행 / 되돌리기(저장 상태로) / 저장 / 취소 / 완료 / 삭제 / 종료.

학습·과제·평가 아이콘은 학부모 리포트와 같다: 학습(학습기록) = 연필(edit-2) · 과제(과제검사) = 클립보드 · 평가 = 글 있는 문서(file-text). 시험 성적은 상장(award).

법정 서류에는 클래스 이름이 아니라 **신고 교습과정명**(클래스 창의 칸)을 쓴다. 비어 있으면 빨간 글 "신고 과정명 없음".

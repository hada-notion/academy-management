# 관리 앱 기준

> 지금 기준만 적는다. 바뀐 이력은 `log.md`, 화면별 동작은 `관리앱-화면명세.md`.
> 새로 만들거나 고칠 때: ① 어느 **영역**인지 정한다 → ② 그 영역에 들어갈 수 있는 **부품**만 쓴다 → ③ 부품은 **공통 코드**로 만든다(화면마다 따로 그리지 않음) → ④ 예외가 필요하면 이 문서 "예외" 칸에 한 줄 적고 만든다.
> 대상: PC·태블릿 업무 화면(관리 앱). 손가락으로 쓰는 화면(학부모 리포트·키오스크)은 9장.

**앱의 자리(대표 261119)** — 관리 앱은 웹앱이다. ① 노션을 돕는다(서포트) ② 서버에 있는 자료를 대신 보여 준다 ③ 노션으로 하기 불편한 일(시간표 입력 등)을 쉽게 한다. **노션을 대체하지 않는다** — 원본은 늘 노션이고, 앱이 없어도 노션만으로 운영된다. 앱 소개·도움말 첫 문장·홈·빈 화면 글도 이 자리에 맞춘다("노션을 대체", "노션 없이", "전부 관리"로 들리는 말을 쓰지 않는다).

## 0. 작업 순서(같게 일하면 같은 결과 — 근거 `작업-방식-분석.md`)
| 순서 | 할 일 | 끝난 표시 |
|-|-|-|
| 1 동선 | 사용자가 실제로 겪는 순서(문의 → 접수 → 등록 → 수업 …)를 따라 어느 화면·탭인지 정한다 | 시나리오 한 줄 |

| 3 구조 | 노션 DB·수식·서버 코드를 읽어 되는 일인지 본다(안 되는 화면을 그리지 않음) | 구조 메모 |
| 4 시안 | 실제 앱 화면을 캡처한 시안 2~3장(`_sian/`). 고르기 전에는 앱을 고치지 않음 | 시안 파일 |

| 7 같은 것 전부 | 같은 부품을 쓰는 다른 화면·칸을 찾아 함께 맞춤, 고친 범위를 보고 | 범위 한 줄 |
| 8 규칙·검사 | 이 문서에 한 줄, 가능하면 검사(`chk-rules` 등)에도 | 기준·검사 |
| 9 기록 | `log.md` 한 줄, 나중 일은 `후순위-요청.md` | — |

## 2. 화면 영역 — 무엇이 어디에 들어가는가
모든 화면은 아래 영역으로만 이루어진다. 영역 밖에 떠다니는 것은 G뿐.

| 영역 | 용도 | 들어가는 것(이것만) | 크기 |
|-|-|-|-|
| **A 머리 줄** | 앱 이동 | A1 메뉴 접기·뒤로·앞으로·앱 이름 / A2 화면 탭 | 높이 44 |
| **B 왼쪽 메뉴** | 화면 고르기 | B1 시작하기 카드 / B2 메뉴(묶음 이름 + 메뉴 줄 + 할 일 배지) | 폭 272(좁으면 아이콘 띠 64) |
| **C 제목 줄** | 지금 보는 것이 무엇인지 | C1 화면 제목 + 개수 또는 날짜·주 이동, 표 편집 표시, 필터 요약 [필터 해제] / C2 시즌 칩(시간표·수업만) / C3 상태 묶음(실제 자료 연결일 때만, 오른쪽 끝 — 점 + 자동 갱신 줄, 그 아래 필요한 화면만 "노션에서 고쳐요" 한 줄) | 높이 54, 제목 22. **제목 아래 설명 줄 없음** |
| **D 위 줄** | 보기 바꾸기·찾기·화면 동작 | D1 보기 탭 · 필터 탭 / D2 찾기 칸 / D3 동작 단추(아이콘만) | 높이 56, 부품 32 |
| **E 본문** | 자료 | 캘린더 또는 표 하나 | 머리 줄 40 |
| **F 오른쪽 창** | 고른 것 하나를 보고 고치기. 아무것도 안 골랐으면 할 일 | F1 창 머리 / F2 창 탭 / F3 본문(묶음 → 라벨 → 입력칸) / F4 아래 동작 줄 | 폭 320~600(기본 360), 안쪽 16 |
| **G 떠 있는 것** | 잠깐 쓰고 닫는 것 | 정보 카드 · 드롭다운·고르기 목록 · 달력·시간 · 알림 · 대화상자 · 모드 바 | — |

- 화면을 바꿔도 C·D·E 머리의 선이 같은 자리(54 → 56 → 40).
- C1 제목 옆 순서: 제목 → (메뉴 단위 나눔 [시간표 | 수업] · [관리자 설정 | 학원 정보] · 링크 [‹ 시간표]) → 개수 → 한 줄 요약 → (?) 설명 → [노션](그 화면과 1:1인 노션 페이지를 새 탭으로, 높이 24·12/600) → 표 편집 표시 → 필터 요약.
- **기간 이동**(둘째 줄 맨 앞, 부품 하나 `CALF.nav`): 기간으로 나뉘는 화면만, 모든 화면이 같은 자리 · 같은 순서 **기간 글자 → ‹ › → [이번 주/달]/[오늘]** → 화면 탭(나눔 단추) → 찾기 → 칩 → 도구(오른쪽). 제목 줄에 두지 않는다. 검사 `chk-layout`(모든 메뉴 화면). 시간표·수업 = 주(‹ › [이번 주] + 날짜 범위), 수강료·가정통신문·손익 분석 결제 내역·법정 서류(출석부·영수증 원부·현금출납부) = 달(‹ › [이번 달] + "2026.11"). 둥근 단추 32, 지금 기간을 보고 있으면 [이번 주]·[이번 달]·[오늘]은 연한 테두리만(누를 일 없음), 다른 기간이면 연한 갈색 단추. 시간표·수업은 제목 줄 = 제목 + 시간표/수업 토글, 둘째 줄 맨 앞 = 날짜(YYYY.MM.DD - YYYY.MM.DD) ‹ › [이번 주], 자리는 화면을 바꿔도 고정. 그 화면의 표·생성·전송·서류가 모두 보는 기간 기준. 기간을 필터 칩으로 만들지 않는다.
- **한 줄 요약**(C1, 13 회색): 그 화면에서 바로 알아야 하는 합계 하나(수강료 = 미납 n건 · 금액, 손익 분석 결제 내역 = 지출 합계). 없으면 비움.

**B2 메뉴 = 노션 메뉴 1~9 순서 그대로, 묶음마다 3개**(묶음 이름·메뉴 이름도 같음)
| 묶음 | 메뉴 [화면 안 탭] |
|-|-|
| 1 운영 | 홈(노션 홈과 같은 위 · 아래: 위 할 일 [우선순위 \| 담당자 \| 캘린더 \| 완료] 보기만 · 아래 오늘 학원 3줄, 앱만 입력 점검 · 바로 가기: 법정 서류 · 키오스크) · 일정 [달력 \| 표 \| 시즌] · 직원 |
| 2 수업 | 수업 [출결 \| 보강] · 보강 [결석 달력 \| 보강 대기] · 학습기록 [학습 \| 과제 \| 평가] |
| 3 학생 | 학생 · 학교 · 시험 |
| 4 수강 | 클래스 · 등록 · 시간표(시즌 고르기 · [운영 시작]만 — 시즌 만들기·고치기는 시즌 고르기 안 [시즌 관리] → 일정 › 시즌) |

| 9 매뉴얼 · 데이터 | 매뉴얼 · 공개 DB · 비공개 DB(새 탭) |
- 노션 메뉴 하나에 앱 화면이 둘이면 화면 안 탭으로 오간다(관리자 설정 \| 학원 정보). 시간표 ↔ 시즌은 탭 없이 시즌 고르기 한 곳.
- **시즌은 일정 메뉴 안**(대표 261118 — 날짜를 다루는 곳에 기간도): 일정 [달력 \| 표 \| 시즌]. 달력 = 일정(숨김 빼고) + 시험 + 시즌(옛 시즌 달력을 합침) — 칸마다 이름 칩 최대 3개(넘치면 오른쪽 위 [+n개 더]) · 여러 날 일정은 시작일·월요일에만 이름, 나머지 날은 얇은 띠 · 휴원 날 = 칸 회색 + "휴원 · 이름" · 색 = 구분(학원 일정 파랑 · 할일 초록 · 시험 주황 · 학교 행사 노랑 · 방학/휴교 회갈색) · 시즌 = 한 번에 하나(눈 아이콘에서 고름, 처음엔 오늘 시즌), 날짜 바로 아래 얇은 선으로 칸을 넘어 쭉 · 시작일·달 첫날에 이름(누르면 오른쪽 창에 그 시즌) · 시즌 색은 3색만(보라·분홍·청록, 이웃 시즌은 다른 색) · 일정 칩은 옅은 테두리만(그림자 없음) · 오늘 = 맨 위 테두리 · 제목 줄 = 기간 이동 → 숨긴 구분 요약 [해제] · 학교는 찾기 칸("일정·학교 검색") · 날짜 칸·[+n] = 오른쪽 창에 그날 전부(구분별) · [필터](필터 아이콘, 표의 [표 편집] 자리, 꺼 둔 구분 수 배지) = 구분 6 체크 · 시즌 하나 고르기(시즌 안 보기 포함) · 과목별 시험일(이 컴퓨터에 기억) · 그 옆 [눈] = 숨김 고르기 모드(달력·표 둘 다, 숨긴 수 배지): 켜면 숨긴 일정도 흐리게 나오고 일정 앞(표는 맨 앞 [보임] 열) 눈으로 숨김 ↔ 보임, 안내 줄 [이 달 학사일정 모두 숨기기 · 모두 보이기 · 끝내기]. 숨김(내부 정리, 나이스 일정은 숨김으로 들어와 쓸 것만 고름)과 학부모 공개(외부, 창 [학부모 리포트] 상자의 나눔 단추)는 모양·자리·말을 겹치지 않게 — 눈 아이콘은 숨김에만, 학부모 공개 칸 아이콘은 사람들, 주간 보기는 두지 않음(일정은 대부분 종일 — 시간 단위는 시간표·수업), 표 필터 탭 = [다가오는 · 학사 일정 · 전체](노션 "학사 일정" 표 보기와 같은 기능), 시즌 = 타임라인(막대를 누르면 오른쪽 창에 그 시즌) + 오른쪽 기본 창 시즌 목록. 노션 `구분`은 6개(할일 · 학원 일정 · 학교 행사 · 시험 · 방학/휴교 · 휴원, 옛 학사 일정을 셋으로 — 대표 261118). 따로 있던 시즌 화면은 없음(옛 주소·저장 탭은 일정 › 시즌으로). 노션은 시즌 자리가 달라도 기능이 같아 1:1.
- **시험 구조(대표 261118)**: 시험(시험 DB) = 그 해 중간·기말 한 번 전체 묶음 · 시험 기간(일정, 구분 = 시험) = 한 학교의 그 시험 기간(나이스가 넣어 줌, 날짜별로 오면 이어진 날을 하나로) · 시험정보 = 학교 × 학년 × 과목(시험 범위·응시 학생, 시험일 = 그 기간 안의 하루) · 응시 학생·성적 = 시험정보에 묶인 학생 한 줄. 시험정보 ↔ 시험 기간은 `시험일정` 연결 — [시험 기간 연결](같은 학교 · 구분 시험 · 이름에 시험 이름 · 그 해) 또는 앱 시험정보 창에서 학교·학년을 고르면 저절로. [시험일정 추가](일정 새로 만들기)는 쓰지 않음. 달력: 일정 달력 = 시험 기간 막대 + 과목 시험일 칩([보일 것] "과목별 시험일") · 시험 메뉴 달력 = 과목 시험일 + 그 학교 시험 기간 배경.

**일정 구분 2단계(261118 대표).** 1단계 구분 = 할일 · 학원 일정 · 학사 일정(노션 수식, 세부에서 저절로) / 2단계 세부 구분(노션 선택) = 할일 · 학원 행사 · 상담 · 테스트 · 학원 휴원 · 직원 회의 · 학교 행사 · 시험 · 방학 · 학교 휴업. 창 [정보]: 구분 [할일 | 학원 일정 | 학사 일정] 나눔 → 세부 구분 고르기, 안내 구분 칸 없음, 일정 안내 메모(상담 알림톡 전달사항)는 [상담] 탭에만. 탭 = [정보 | 세부 탭 | 공개]: 할일 [메모] · 직원 회의 [회의록](기록(내부용) 칸, 자물쇠) · 상담 [상담](학생 · 반 · 일정 안내 메모 · 받는 학부모 · 전송) · 학원 휴원 [쉬는 수업](반 + 그 기간 시간표 수업) · 테스트 [테스트](대상 · 학생 목록) · 시험 [시험정보](학년별 과목 시험일, 연결 안 됨 꼬리표). 할일 · 직원 회의는 [공개] 없음. 머리 둘째 줄 = 구분 · 세부. 일정 달력에는 과목별 시험일 칩 없음(시험 메뉴 달력에만). 옛 자료(세부 없음)는 옛 구분 + 안내 구분으로 읽음.

**일정 학부모 공개(261118 대표).** 일정 창 탭 = [정보 | (세부 탭) | 공개](할일 · 직원 회의는 [공개] 없음, 옛 탭 이름 [학부모] → [공개]) — 학부모 공개(바깥)는 [학부모] 탭, 숨김(안쪽 정리)은 위 줄 눈 단추로 자리부터 떨어뜨려 "다른 것"임이 드러나게. 공개 여부는 창 머리 줄 "학부모 공개"로 탭을 안 열어도 보임(탭 모듈은 숫자를 달지 않음). [학부모] 탭의 [학부모 리포트] 상자 = 학부모 공개 [공개|비공개] 나눔 + (공개 · 휴원 · 상담일 때) 대상 관계 칸 네 개 클래스 · 학생 · 학교 · 학년(노션 관계 칸 그대로 — 대표 261118 "관계형을 입력한다는 느낌이 노션과 닮아 노션 사용에도 오해가 없음", 방식 하나 고르기 안은 버림. 클래스 칸은 휴원 때 "쉬는 반"도 겸함 — 한 칸) + 공개 상태 한 줄(노션 수식 글, 섞이면 ⚠️) + 보이는 학생 명단(N명 · 늘 쓰는 줄 목록 PANEL.rows 처음 5줄 + [n명 더 보기] · 줄 = 이름 / 학교 학년 · 누르면 학생 · 연락처 없는 학생은 맨 아래 "연락처 없음" 꼬리표 — 칩은 쓰지 않음, 대표 261118 기준 통일). 막지 않고 보여 줌(대표 "더 강제할 수 없다 — 의도라면 막을 수도 없다"). 상담이면 그 아래 [상담 일정 안내] 상자 = 받는 학부모 명단(고른 학생 + 고른 반 등록 중, 학교·학년·공개는 안 봄) + 공개 꺼짐이면 "그래도 알림톡은 나가요" 회색 안내 · 공개인데 학교·학년도 골라 리포트 쪽이 더 넓으면 ⚠️ "알림톡은 a명에게만, 리포트·가정통신문엔 b명 — 상담은 학생만" + [일정 안내 전송](관리 앱은 꺼짐 — 보내기는 노션). 표시는 두 단계뿐: 회색 안내 / ⚠️ 확인. 할일은 [공개] 꺼짐, 숨긴 일정은 [공개]를 새로 켤 수 없음. 리포트에 보이는 학생 = 서버 규칙 그대로(바꾸지 않음): (학생) 또는 (등록 중인 클래스) 또는 (학교 그리고 학년, 빈 칸은 맞는 것으로), 같은 칸 여러 값 = 또는, 대상 없음 = 모든 학생, 숨김이 이김. 공개 상태 글 = 노션 일정 DB "공개 상태" 수식과 같은 표(앱은 저장 전에 같은 규칙으로 계산, 저장 뒤 노션 값):

| 상태 | 조건 | 글 |
|-|-|-|
| 비공개(할일) | 구분 할일 | 비공개 · 할일은 학부모 리포트에 나가지 않아요 |
| 비공개 | 학부모 공개 꺼짐 | 비공개 · 학부모 리포트에 나가지 않아요 |

| 공개 | 공개 켜짐 + 숨김 아님 | 공개 · {대상}에게 보여요 — 대상 = 학생 이름 하나하나 · "{클래스} 학생" 하나하나 · 학교×학년 짝마다 "{학교} {학년}"(학년 없으면 "{학교} 모든 학년", 학교 없으면 "모든 학교 {학년}")을 모두 ", 또는 "로 이음, 없으면 "모든 학생". ⚠️ 줄은 맨 앞 "⚠️ ", 경고 여럿은 " / "로 (노션 수식 원문 `과제\261117-노션완성\결과\원문\일정-공개상태-수식-261118.md`) |
| ⚠️ 공개 | 위 + 학생과 다른 대상 함께 | … — 학생과 다른 대상을 함께 고르면 그 학생 말고도 보여요 |
| ⚠️ 공개 | 위 + 클래스와 학교·학년 함께(학생 없음) | … — 클래스와 학교·학년은 '또는'이라 범위가 넓어져요 |
| ⚠️ 공개 | 위 + 휴원인데 클래스 없음 | … — 반을 안 골라 수업은 그대로 생겨요 |

구분 고르기 = 노션 6개(학원 일정 · 할일 · 시험 · 학교 행사 · 방학/휴교 · 휴원), 값은 노션 옵션 이름 그대로.
- 보강 메뉴는 결석·보강 상태를 보는 곳이고, 보강을 만드는 곳은 수업 화면 보강 모드 하나다([보강 잡기] = 그 학생을 미리 고른 채로 수업 [보강]).
- 제목 아이콘은 탭 따라 바뀐다(라이브러리 교재 ↔ 프로그램, 청구서 기타경비 목록).
- 노션에서 여러 페이지인 것을 앱에서 한 화면으로 합친 곳: 학생(신규문의 · 학생 현황 → 등록상태 칩), 시험(성적 → 창 탭), 청구서(기타경비 → 탭).
- 새 화면을 넣을 때: 노션 메뉴에 있으면 그 묶음·그 이름으로, 표로 보는 자료면 4장 표 부품 정의(열·칸·필터)만 더한다.
- 설명 글은 화면에 늘어놓지 않고 제목 옆 (?)에. 화면에 남기는 글 = 경고 · 빈 상태 · 값·개수.

**두 줄 나누기(모든 화면 같음, 261117 대표)**: 보기 탭을 바꿔도 둘째 줄이 움직이지 않게.
- **제목 줄(C) = 언제·어느 범위를 보나**: 화면 이름 → (?) → [노션] → **기간 이동**(주·달 ‹ › [이번 주/달], 있는 화면·보기만) ··· 오른쪽 끝 **범위 고르기**(시간표·수업의 시즌처럼 있는 화면만). **상태 묶음(C3, `#pgStat`)은 모든 화면 제목 줄 맨 오른쪽 끝 한 자리**(표 화면 · 수업 화면 같은 곳, 줄 위에 붙임): 위 = **연결 점**(초록 = 노션 변경 자동 반영 연결됨, 회색 = 다시 연결 중 — 점은 이 자리에만) + "자동 갱신 켜짐 · 마지막 받음 HH:MM"(11.5 옅은 글자), 아래 = **보기만 안내 한 줄**(보기만 하는 화면만: "고칠 것은 노션에서 고쳐요" · 학교 "이름 · 기간은 노션에서 고쳐요" · 댓글 권한 메뉴). 부품 = live.js `liveSyncMount` · `roLinePlace` 한 곳. **제목 아래 설명 줄은 어느 화면에도 두지 않는다** — 설명은 (?)에, "화면의 단추로 노션에 써요" 같은 단추 설명 글 없음. **제목 옆 개수 없음** — 개수는 오른쪽 기본 창(할 일 창) 머리 "화면 이름 · n개"에.
- **둘째 줄(D) = 어떻게 보고 다루나**: **보기 탭**(D1, 맨 앞 고정 — [표\|달력] · [시간표\|수업] · 학생 등록상태 · [결석 달력\|보강 대기]) → **필터 탭**(표 메뉴) 또는 모드 탭(달력: [편집\|추가] · [출결\|보강]) ··· 오른쪽: **찾기 칸 → D3 단추**(찾기 칸은 늘 D3 바로 앞 — 탭 길이와 상관없이 모든 화면 같은 자리).
- **필터 칩은 쓰지 않는다 — 필터 탭으로**(대표 261117). 보기 탭 = 보이는 것이 바뀜(달력\|표 · 과목\|영역 · 학교\|학년 · 청구서 종류) → 왼쪽, 필터 탭 = 같은 자료를 좁힘 → 그 오른쪽. 보기 탭이 없으면 필터 탭이 맨 왼쪽(학생). 필터 탭 모양 = **[기본 묶음][다른 묶음…][전체]**, 맨 왼쪽이 처음 열 때 고른 탭(예: 등록 = 수강 중), 전체는 끝, 탭마다 숫자, 한 번에 하나. 기본 탭이 0건이거나 찾은 줄이 없으면 빈 화면에 [전체 보기]·[전체에서 찾기]. 고른 줄을 들고 열었는데 기본 탭에 없으면 전체(학생은 그 학생의 등록상태 탭)로 연다. 화면은 `L.ftabs`만 정하고 그리기·숫자·빈 화면은 공용 한 곳(`ftHtml`). 달력 보기에는 필터 탭 없음. 탭으로 안 옮긴 거르기(빈칸·종류)는 열 머리 필터와 오른쪽 할 일 창으로.
- **표 메뉴 위 줄엔 화면 고유 단추(생성 · 전송 · 가져오기)를 두지 않는다** — 오른쪽 기본 창(할 일 창) 아래 단추 줄로(옮기기는 페이지 정리 뒤, 대표 261117). **한 줄(한 학교 · 한 등록)에 딸린 일은 기본 창이 아니라 그 줄의 창 안, 그 일이 쓰는 칸 바로 아래**에 단추 + 상태 글(꺼지면 이유)로 — 예: 학교 창 [학사일정] 묶음 = 가져올 시작일 · 종료일 → [학사일정 가져오기](그 학교만, 대표 261124). 서버가 한 번에 여러 줄을 맡으면 멈춘 일이 있어 묶음 단추를 두지 않는다. 그래서 표 메뉴 D3 = 공통 단추만 → 찾기 칸 자리가 19곳 모두 같다. 달력 화면(시간표 · 수업)의 고유 단추([인쇄] · 보기 크기 · [5\|7] · [⊞ n])는 위 줄에 남김.
- 필터 탭 숫자(등록 중 51 · 전체 62 등)는 탭의 일부라 남김(좁으면 숨김).

**D3 순서(모든 화면 같음)**: 화면 고유 동작 → [↰ 실행 취소\|↱ 다시 실행] → [↺ 저장 전으로 모두 되돌리기] → [저장 n] → [창].
- 저장은 늘 [창] 바로 앞. [↺]는 고친 것이 있을 때만 켜짐.
- **위 줄은 어떤 폭(768 이상)에서도 한 줄 56**이다. 오른쪽 D3은 줄지도 · 겹치지도 · 줄바꿈되지도 않고 늘 같은 자리. 자리가 모자라면 **왼쪽만** 차례로 접는다: ① 찾기 칸 줄임 ② 거르기 역할 단추 묶음(보기 탭) → 드롭다운 하나(지금 고른 이름 + ▾, 누르면 나머지) ③ (필터 탭 숫자 숨김) ④ 찾기 칸 → 아이콘(누르면 펴짐). 모든 화면의 위 줄이 한 곳(`fitBars`)을 쓴다 — 화면이 따로 접지 않는다(대표 261117, 검사 `chk-topbar`: 1020 · 1280 · 1400에서 한 줄 · 단추 겹침 0 · 줄 밖 0).
- D3 단추는 폭과 상관없이 아이콘만. 글자가 있는 것은 D1·D2뿐.
- 화면 고유 동작: 시간표 [인쇄] [보기 크기] [5\|7] / 수업 [⊞ n] [보기 크기] [5\|7] / 표 화면 = **네 자리 고정**.
- **화면 고유 동작 단추**(노션 버튼이 하던 일: 생성·일괄 전송·가져오기): 네 자리 **왼쪽**에 숫자 단추(흰 바탕, 아이콘 16 + 대상 수)로, 화면마다 최대 2개. 대상이 0이면 꺼짐. 누르면 확인 창(무엇을 몇 건, [취소][생성·보내기]) → 한 뒤 알림 "Ctrl+Z로 되돌려요". 표 편집 중에는 숨김. 아이콘: 생성 = 더하기 네모, 전송 = 종이비행기, 가져오기 = 달력.
- **표 화면 네 자리**(모든 표 화면·두 모드에서 자리가 같음): 평소 [엑셀] [표 편집] [인쇄] [추가] → 표 편집 중 [열 정리] [완료] [취소] [추가]. [표 편집]과 [완료]는 같은 자리(같은 단추가 켜고 끔). [추가]가 없는 화면·표 편집 중에는 자리를 비우지 않고 **꺼진 단추**로 두고, 이름에 이유를 적는다.

| 표 편집 칸 이동 | 모든 표가 같다(엑셀 방식, 표 편집 중에만 — 평소엔 줄을 누르면 창): **한 번 클릭 = 칸 선택**(진한 테두리 2), 방향키로 칸 이동, Tab = 오른쪽(줄 끝이면 다음 줄 첫 칸) · Shift+Tab = 왼쪽. **두 번째 클릭 · 더블클릭 · Enter · F2 = 입력칸 열기**, 선택한 글 칸에서 바로 글자를 치면 그 글자부터 입력. 입력 중 **Enter = 저장 + 아래 칸 선택**, Tab = 저장 + 오른쪽 칸 선택(다음 입력칸은 열리지 않음), **Esc = 취소(입력 전 값으로 되돌리고 칸 선택으로)**, **다른 칸 클릭 = 저장 + 클릭한 칸 선택**(엑셀과 같다), 긴 글 칸은 Enter = 저장 · Shift+Enter = 줄바꿈. 선택 테두리(진한 2)는 마우스를 올린 칸 표시(옅은 1)보다 늘 진하다. 고칠 수 없는 칸도 선택은 되고 지나간다(Enter를 눌러도 안 열림). 켜기·끄기 · 나눔 칸은 입력칸에서 눌러야 바뀐다(입력칸에서 좌우 키 = 고르기, Enter = 고른 것 저장 + 아래 칸). 합친 칸(등록 표 학생 · 학교 · 학년)은 한 칸으로 움직인다. Delete로 칸 비우기는 없다(입력칸을 열어 지움). 입력칸은 들어 있는 글자가 잘리면 그만큼 넓어지고(최대 380), 고르기 목록은 가장 긴 줄만큼 넓어진다(최대 360) — 잘린 글자 없음(검사 x/_audit-cells). 표 편집을 켜면 오른쪽 창은 잠시 접히고(넓은 표의 오른쪽 열이 가려지지 않게) 끄면 다시 열린다. 표 편집 중 칸 안의 이동 칩(등록 등)은 이동하지 않고 칸 선택 |
| 표 편집 칸 모양 | 칸을 누르면 **오른쪽 창과 같은 입력칸**(같은 고르기 목록 · 달력 · 검사)이 그 칸 자리에 칸 모양으로 뜬다: 칸 높이 그대로 · 각진 테두리(진한 선 2) · × 없음 · 칸 이름 없음. 글이 길어 칸보다 넓어야 하는 날짜(150) · 날짜+시각(230) · 요일(320) · 여러 개 고르기(240)만 오른쪽으로 넓어진다 |
| 다른 데이터의 칸 | 표에 다른 화면의 데이터가 보일 때(등록 표의 학생 이름·학교·학년)는 **보기만** — 표 편집 중에도 고치지 않고, 누르면 그 데이터가 사는 화면(학생 · 학교)으로 간다. 데이터는 그 데이터가 사는 화면에서만 고친다 |
| 계산 칸 | 수식으로 정해지는 값(등록상태 등)은 **입력칸과 같은 모양의 보기만 칸**(흐린 바탕 · 고칠 수 없음)에 값과 범위를 보여 주고, 아래에 "자동 계산 — 왜 이 값인지" 한 줄. 부품 `calcField` 하나 |
| 등록 창 [정보] | 묶음 순서: **학생**(이름 · 학교 · 학년 — 보기만, 제목 오른쪽 [학생 열기]) → **수강 등록**(클래스 · 담당 강사(클래스에서 자동) · 등록상태(계산 칸) · 등록일 - 종료일) → 안내 → 수강료 조정 → 종료 → 메모. 등록 표 [+]로 만든 새 등록만 학생 칸이 "검색 또는 추가"로 켜지고(새 학생이면 학교 · 학년도 그 자리에서), 클래스도 새 등록일 때만 고른다(저장한 등록의 반 바꾸기 = [종료 처리] 뒤 새 등록). 보기만 칸에는 설명 글을 넣지 않는다. 학생 · 클래스를 고르기 전에는 [정보] 탭만 보이고 저장되지 않는다 |
| 창 [시간표] 탭 | **창 안에서는 목록만**(주간 달력은 시간표 화면 하나). 머리 한 줄 = 시간표 n개 · 시즌 고르기. 줄 = 요일 시간 · 강사 · 인원 · [그룹\|개별]. **등록**: [그룹] = 클래스 시간표(등록하면 모두 들어감, 빠지는 요일만 체크 해제) · [개별] = 이 학생만의 시간(다른 학생 개별은 안 보임) — 아래 상자에서 요일(여러 개면 한 번에 여러 개) + 시작 - 끝 → [개별 시간 추가](기본 길이 = 클래스 수업 시간), 이 학생의 다른 수업과 겹치면 빨간 글로 알림, 개별 줄을 누르면 그 상자에서 바로 고침([시간 바꾸기]), × = 그 개별 시간 삭제(저장 전까지 되돌림). **클래스**: 목록(누르면 시간표 화면) + [시간표 추가](이 클래스로 걸러진 시간표 화면). 아래 "시간표 화면에서 보기" = 등록은 이 학생, 클래스는 이 클래스로 걸러서 연다 |
| 진도 진행도 · 수료 | 진행도 = 노션 진도관리 DB `진행도` 수식과 같다: 다음 교재 = 0% · 진행 중 = 학습기록(보강 제외) 범위 끝 ÷ 전체 분량 중 **가장 큰 값** · 완료 = **100%**(학습기록과 상관없이) · 미사용 = 빈 값. 완료와 수료는 두 단계다: 진행상태 "완료"는 어디서든 그냥 고른다 → **[수료]는 진행상태가 완료일 때만 눌린다**(그 밖에는 꺼짐 + "진행상태가 완료일 때 눌러요"). [수료] = 수료일 오늘 · 수강생이 있으면 수료 보고서 발송함 생성(노션 [수료] 버튼 → 서버와 같은 일). 수료한 뒤 [수료 보고서](한마디 쓰기 = 학습 보고서 화면) · [보내기](전송 확인 창). 완료에서 다른 상태로 돌리면 "수료일을 지우고 다시 진행할까요?"(이미 만든 수료 보고서는 남음) |
| 진도 줄 펼치기 | 창 [진도] 탭 · 라이브러리 [진도관리] 탭의 진도 줄(리스트 보기)은 한 번 누르면 이동하지 않고 그 줄 아래가 펼쳐진다(한 번에 하나, 다시 누르면 접힘): 진행상태(고르기 알약 넷) · 최근 학습 범위 · 최근 학습(누르면 그 수업 [학습기록]으로) · 수료 단추 줄 · 오른쪽 끝 [교재로 이동](프로그램은 [프로그램으로 이동] = 예전 줄 누르기와 같은 창 안 이동). 카드 보기는 그대로 눌러 이동. 그리는 곳 = 창 모듈 `PANEL.bookRows`(줄 `attr` · `more` · `on`) |
| 진도 탭 교재·프로그램 | 창 [진도] 탭 머리 = [교재 n · 프로그램 n] 전환(이름 자리, 마지막 고른 쪽을 기억 · 고른 쪽이 0권이고 다른 쪽이 있으면 다른 쪽을 보임). 목록 · 묶음 수는 고른 쪽만 |
| 보고서 묶음·개별 | 노션과 1:1: **묶음** = 알림톡 발송함(학습 보고서 화면 표 한 줄 · 클래스 · 구분 · 기간) · **개별** = 보고서 DB 한 페이지(학생 한 명 · 선생님 한마디 · 보고서 전송 상태 ✅ 보냄 · ⚪ 전송 전 · ⚠️ 오류, 본문은 노션 페이지). 묶음 창 = [정보](묶음 칸 + 보내기 현황 + 머리 [전송 n]) · [학생 n](학생 줄 = 개별 보고서, 거르기 [전체 · 전송 전 · 한마디 없음] + 머리 [전송 n]). 학생 줄 한 번 누름 = 펼침(진도 줄과 같은 부품 `PANEL.bookRows`): 선생님 한마디 칸 · 알림톡 칸(표준 `hf rcpt` — [보고서 전송] / [다시 전송], 누르면 알림톡 미리보기 → [보내기]) · [노션에서 열기] · [학생으로 이동]. 클래스 공통 한마디는 없다(한마디는 학생마다). 학생 창 · 등록 창 [보고서] 탭 = 그 학생(등록)의 개별 보고서만 같은 줄로(거르기 [전체 · 주간 · 월간 · 수료], 펼침에 [묶음 열기]). 묶음 [전송 n] = 전송 전 · 오류인 학생만 |
| 클래스 구분 · 유형 · 개강일 · 종강일 | 노션 클래스(학원) DB와 1:1: **클래스 구분** [교과 | 예체능](노션 `클래스 구분`, 옛 이름 `알림톡 구분` — 예체능이면 보고서 템플릿이 주간·월간 활동 보고서, 수료는 프로그램 수료 보고서이고 수료 과정 줄이 🎨 프로그램) · **클래스 유형** [정규 | 특강](노션 `클래스 유형`) · **개강일** · **종강일**(노션 같은 이름 — 개강일 앞 · 종강일 뒤에는 수업을 만들지 않고, 운영 상태 = 개강 전 / 운영 중 / 종료). 보고서 템플릿 이름은 클래스 구분 하나로 정한다(서버 `isArtsClass`와 같음) |
| 시간표 변경 안내 | 노션 등록 · 클래스 [시간표 변경 안내]와 같다. 등록마다 **안내한 시간표**(마지막으로 알린 요일·시간)를 기억하고, 지금 시간표와 다르면 보낼 대상. 등록 창 [시간표] 탭 아래 = 이 학생 알림톡 칸(표준 `hf rcpt`, 다를 때만 켜짐 · "안내한 시간표 → 지금"), 클래스 창 [시간표] 탭 아래 = `시간표 안내 메모`(50자) + 보낼 학생 목록 + 머리 [전송 n](같은 시간표로 이미 안내한 학생은 건너뜀). 전달사항 = 등록 안내 메모, 비면 클래스 시간표 안내 메모, 비면 "없음". 보내면 안내한 시간표 = 지금 · 등록 안내 메모 비움 |
| 청구 항목 종류 | 노션 청구 항목 `종류`와 같다. 직접 넣는 줄의 종류 = **교재비 · 기타경비** 두 가지(`seg`). 기타경비 항목 = 교육지원청에 신고한 여섯 가지(모의고사비 · 재료비 · 피복비 · 급식비 · 기숙사비 · 차량비), 교재비 항목 = 교재비 하나. **교습비** 줄은 수강료에서만 생성(보기만, 고르지 못함). 영수증 원부 = 교습비 + 기타경비, 교재비 줄은 넣지 않는다. 특강비 · 행사비 · 간식비처럼 신고하지 않은 돈은 청구에 넣지 않는다(특강은 클래스로 등록) |

## 4-1. 카드 화면 — 표·캘린더가 아닌 화면(학원 정보·관리자 설정)
| 항목 | 기준 |

| 구성 | C 제목 줄 + E 묶음 카드. D 위 줄·F 오른쪽 창 없음(찾거나 고를 것이 없음) |

## 6. 캘린더(E)
- 요일 머리 40. 블록 = 클래스 색 옅은 바탕 + 왼쪽 띠 4, 이름 13/700 → 시간 → 강사 → 인원(모자라면 아래부터 뺌, 이름은 자르지 않고 두 줄 → 약칭).
- 휴원 제외(매뉴얼 6-2-1 · 11-2): 일정의 구분이 **휴원**이고 [클래스]와 날짜가 있으면, 그 클래스의 그 기간 수업은 생기지 않는다 — 수업 달력에 블록이 없고, [수업 생성]·할 일 "수업 없음"에도 세지 않는다. 클래스를 안 고르거나 날짜가 비면 제외되지 않는다(일정 창이 그 사실을 알려 줌). 판정은 `closedOn(시간표, 날짜)` 한 곳. 휴원인 날은 수업·시간표 달력 요일 머리 날짜 옆에 [휴원] 알약(회색) — 모든 클래스가 쉬면 "휴원", 일부면 "휴원 n"(툴팁 = 쉬는 클래스). 요일 머리는 `dayHead` 한 곳.
- 겹치면 나란히. 고르면 진한 테두리. 작성 중 = 점선. 지금 시각 = 빨간 선(블록 위).
- 끌기: 끄는 블록은 칸 전체 폭 · 놓을 자리 잔상은 실제 배치대로(겹치면 나란히) · 제자리 잔상 · 위아래 끝에서 저절로 스크롤 · 휠을 굴려도 커서를 따라옴 · Ctrl+휠 = 보기 크기 · Esc = 취소.
- 잠금은 시즌 상태로 정한다: 운영 중 시즌의 시간표·만든 수업 = 자물쇠를 풀어야 옮김 · 예정 시즌 = 잠금 없음 · 종료 시즌 = 늘 잠김(못 풂). 잠금과 오른쪽 창은 서로 영향 없음.
- 잠금 = 실수 방지 하나(대표 261118): 모든 화면이 **자동 잠금 + 창 머리 이름 옆 자물쇠**. 잠금 값을 저장하는 칸은 두지 않는다(노션 일정 `잠금` 칸 버림). 일정은 학사 일정(나이스에서 온 시험 · 방학 · 학교 행사 · 학교 휴업)이 늘 잠김 — 끌기 막음 · 창의 날짜 칸 꺼짐 · 자물쇠는 풀 수 없음(저장 층도 날짜를 보내지 않음). 학원 일정 · 할일은 잠금 없음.
- 시간표 보기 = [클래스별 | 요일별 | 주간] + 시즌 고르기 하나(대표 261118): 필터 탭(이번 · 다음 · 전체) 대신 보기 탭 옆 시즌 칩 — 세 보기가 같은 시즌, 목록 = 시즌마다 상태 알약 · 개수, 표에만 "모든 시즌", 주간에만 "시즌 관리"(타임라인). 주간의 [편집 | 추가]는 없고 위 줄 [+]가 추가 모드를 켜고 끔(켜지면 눌린 모양, Esc · 다시 누르면 끝). 끌기 · 잠금 · 되튐은 표준 주간 달력(CALW) 그대로.
- 두 칸 = 이름 두 개(대표 261118): 시작·끝을 한 줄에 둔 칸(날짜 · 시간 범위)도 칸마다 이름을 단다 — 시작일 · 종료일, 시작 시간 · 종료 시간, 등록일 · 종료일, 개강일 · 종강일. "시작일 - 종료일"처럼 한 이름으로 묶지 않고 가운데 줄표도 없음. 입력칸 모듈 범위 칸(`range` — dateRange · timeRange) 한 곳이 그림(이름은 labels, 없으면 " - "로 나눔, 시간은 시작 시간 · 종료 시간). 칸 설명(?)은 앞 이름에.
- 창 머리 오른쪽 위 작은 단추(`PANEL.head` tools, 노션 단추 앞): 그 창 하나에 하나뿐인 동작만(시간표 [수업 추가]). 아래 단추 줄은 저장 · 삭제 · 되돌리기.

| 삭제 | 바로 지우지 않고 "삭제 예정" → [저장] 때. 이어진 것이 있으면 막음 |
| 확인 창 | 되돌릴 수 없거나 여러 건이 함께 바뀔 때만. 처음 커서는 [취소]. **늘 앱 팝업(`askRun`)** — 브라우저 기본 창(confirm·alert)은 쓰지 않는다. 팝업 = 제목 질문 한 줄("이 등록을 종료할까요?") + 누구·무엇(굵게) + 일어나는 일 목록(무엇이 바뀌고 무엇이 남는지) + 회색 한 줄(저장해야 노션에 반영 등) + [취소][동사 하나](종료 · 다시 열기 · 바꾸기 · 재발급) |
| 여러 건을 다루는 창(저장·생성·전송) | **무엇이·누구에게**를 목록으로 보여 준다(줄 28, 이름 + 회색 보조 글, 8~10줄 넘으면 "외 n건"). 건수만 보여 주지 않는다 |
| 보내기 대상 | 이미 끝난 줄(결제를 마친 수강료 등)은 대상에서 뺀다. 창에 그 규칙을 한 줄로 적는다 |
| 방금 생긴 줄 | [생성]·[추가]·올리기로 생긴 줄 = 왼쪽 초록 띠 + 옅은 초록 바탕(8초). 방금 생긴 줄만(자료 전체 기준) — 탭·필터를 바꿔 보이게 된 줄은 칠하지 않는다 |
| 모아 보는 표의 값 | 다른 화면에서 계산해 오는 표(법정 서류·손익 분석)는 (?)에 값이 어디서 나오는지 적고, 자료가 없으면 0이 아니라 "—"·"자료 없음" |
| 모드 | 평소와 다르게 동작할 때(추가·보강·표 편집) 화면 아래 가운데 모드 바. 들어갈 때 알림은 없음 |

## 8. 말·표기

학습·과제·평가 아이콘은 학부모 리포트와 같다: 학습(학습기록) = 연필(edit-2) · 과제(과제검사) = 클립보드 · 평가 = 글 있는 문서(file-text). 시험 성적은 상장(award).

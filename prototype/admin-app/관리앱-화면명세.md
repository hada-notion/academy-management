# 관리 앱 화면 명세

> 화면별 동작만 적는다. 영역·부품·크기·공통 규칙은 `관리앱-기준.md`가 기준이고, 여기와 다르면 기준이 맞다.

## 1. 움직임
| 무엇 | 언제 | 움직임 | 시간 |
|-|-|-|-|
| 오른쪽 창 | 열 때 / 닫을 때 / 띄우기↔고정 | 오른쪽에서 밀려 들어옴 / 오른쪽으로 빠짐 / 살짝 흐렸다 또렷 | 0.18초 |
| 잠긴 블록 끌기 | 누른 채 끌 때 | 끈 방향 그대로(각도 정확) 고무줄처럼 따라오다 멈춤: 거리 = 7·(1 − 1/(끈 거리/45 + 1)), 최대 7px → 24px 넘으면 붉은 테두리 | 끄는 동안 |
| 잠긴 블록 놓기 | 24px 넘게 끌고 놓을 때 | **감쇠 용수철 계산**(진동수 9.5Hz, 감쇠비 0.18): 당긴 자리에서 튕겨 돌아와 당긴 방향으로 왔다 갔다 하며 점점 줄어듦(첫 되튐 6px) + 휴대 기기 진동 + 아래 짧은 알림 → 멈추면 붉은 테두리 사라짐. 24px 안 되면 같은 용수철을 감쇠비 0.55로(되튐 거의 없이 돌아오기만) | 약 0.45초 |
| 블록 옮기기·늘리기 | 끄는 동안 | 마우스를 그대로 따라감, 놓일 자리에 점선 칸 | 끄는 동안 |
| 띄운 오른쪽 창 밀어내기 | 블록·카드를 끌다 창 왼쪽 끝 가까이(24px) 가면 | 창이 오른쪽으로 밀려나 가장자리만 남고 흐려짐(누를 수 없음) → 가려졌던 칸에도 놓을 수 있음. 왼쪽으로 80px 넘게 돌아오거나 놓으면 제자리 | 0.18초 |
| 지금 시각 선 | 이번 주 | 빨간 선이 1분마다 내려옴 | 1분 |
| 목록·메뉴 줄 | 마우스를 올릴 때 | 연갈색 바탕으로 바뀜 | 0.12초 |
| 알림 | 무언가 끝났을 때 | 아래 가운데에 잠깐 뜸(모드 바가 있으면 그 위) | 약 2.5초 |
- 용수철 숫자(최대 당김 7px, 진동수 9.5Hz, 감쇠비 0.18, 첫 되튐 6px)는 코드 한 곳(`SPRING`)에 있고, 바꾸면 당김·튕김·흔들림이 함께 바뀐다.
- 새로 움직임을 넣으면 이 표에 한 줄 더한다. 원본 `docs/DESIGN.md`에는 지금 "움직임 줄이기 설정에서는 애니메이션을 멈춘다" 한 줄뿐 — 원본 구현 때 이 표를 옮긴다(13장).

## 2. 시간표
- **블록**: 클래스 색 연한 바탕 + 왼쪽 띠 4, 제목 13/700 → 시간 → 강사 → 인원, 모자라면 아래 줄부터 뺌, 좁으면 약칭. 고르면 진한 갈색 테두리. 작성 중 = 점선. 기준 주 밖·찾기 밖 = 흐림. **현재 시각 선**(빨간 선 + 점)은 블록 위로 지나감(구글 캘린더처럼), 시각 글자는 쓰지 않음. **블록 끌기**(시간표·수업·보강): 칸 위·아래 끝 56px 안으로 가면 저절로 스크롤(끝에 가까울수록 빠름), 끄는 중 휠을 굴려도 블록이 커서에 붙어 따라오고 놓으면 그 시간. 끄는 블록은 겹쳐 좁아져 있었어도 **칸 전체 폭**으로 커지고, 놓을 자리 잔상(점선)은 **실제로 들어갈 배치 그대로** — 겹치면 나란히 좁아지고 그 칸 기존 블록도 같이 좁아짐(빠진 칸은 다시 넓어짐). 끄는 동안 **제자리 잔상**(옅은 점선)이 원래 자리에 남고, 잔상 위로 가져가도 잔상과 칸을 나누지 않음. 자석은 없음(미세 조정 방해). 제자리에 그대로 놓으면 바뀐 것 없음(저장 수 그대로), **끄는 중 Esc = 끌기 취소·제자리로**. 끄는 중 **Ctrl(Alt)+휠 = 보기 크기**: 끌기는 이어지고 커서 아래 시각은 그대로.
- **같은 시간 여러 클래스**(세션 수업): 나란히 놓음. 4겹 이상도 그대로(정보 카드로 보완).
- **[편집]**: 블록을 눌러 고르고 끌어 옮김. **운영 중**(수업 있음) 시간표는 잠김 — 자물쇠(창 머리·정보 카드)를 풀어야 옮김·늘리기·요일·시간. 거부 표시(움직임 표 "잠긴 블록 끌기"): 조금만 따라오다 멈춤 → 24px 넘으면 붉은 테두리 → 놓으면 용수철처럼 튕겨 돌아온 뒤 흔들림·진동·안내 → 테두리 사라짐. 클릭할 때 손 떨림(24px 이하)으로는 안 나옴. 그냥 누르면 평소대로 고름. 움직임 줄이기 설정이면 흔들림 없음. 다른 블록을 고르면 다시 잠김. 학생 넣고 빼기는 잠금과 상관없음.
- **늘리기**: 위 끝 = 시작, 아래 끝 = 끝(마우스 올리면 손잡이). 끌 때 놓일 자리에 점선 칸 "화 16:00-17:00".
- **[추가]**: 빈 칸(블록 위도)을 끌어 새 시간표. 만드는 중엔 다른 빈 칸을 눌러도 사라지지 않음(깜빡임 + 안내). 점선 칸도 끌기·늘리기. Esc·Delete = 취소.
- **시간표 창 탭** `[수업 일정] [클래스] [학생 n/m]`:
  - 수업 일정: 수업 요일 · 수업 시간(시작 - 끝) · 적용 기간(시작 - 끝), 입력칸 모듈(11장) — 왼쪽 아이콘 + 왼쪽 정렬, 요일 = 드롭다운 목록, 시간 = 휠(5분 단위, 캘린더 끌기와 같은 단위), 날짜 = 직접 입력 + 달력. 적용 기간 기본 = 시즌을 클래스 개강·종강으로 좁힌 것, 바꾸면 [기본으로].
  - 클래스: 새 시간표·수업 없는 시간표 = **클래스 목록**(10장), 운영 중 = 이름 + 색(바꿀 수 없음). 색은 클래스마다 하나, 다른 운영 클래스가 쓰는 색은 막음.
  - 학생: **학생 고르기 목록**(10장) + 클래스 전체 표(요일별 ✓, 이름을 끌어 다른 요일에) + [클래스에 학생 추가](학생 추가 창, 시간표 모두에).
- **동작 줄**: 새 시간표 [취소] [임시저장] [저장] / 기존 [종료](운영 중)·[삭제](수업 없음) … [저장](같은 클래스 여러 개면 "저장 n").
- **운영 중 시간표 고치기**: 요일·시간·학생을 바꾸면 작성 중으로 남고, [저장] 때 **"언제부터"** 한 번(달력: 수업일만, 생기는 날 초록 빗금 +, 지우는 날 빨간 빗금 ✕, 오른쪽 줄글). 그날 이후 이미 만든 수업은 앱이 새 시간으로 함께 옮김. 학부모 안내는 자동으로 안 나감(저장 뒤 [시간표 변경 안내]).
- **[종료]**: 자물쇠를 풀어야 누름. "언제 종료하나요?" 달력(그 뒤 이미 만든 수업 빨간 빗금). 같은 클래스 다른 요일 함께 종료 칩, 모두 끝나면 "클래스 종강일도 맞추기". **[삭제]**: 수업 없는 시간표만, "삭제 예정"으로 두었다가 저장 때 삭제.
- **겹침**: 같은 클래스 같은 시간 = 막음. 학생 = 그 시간 다른 수업이 있으면 체크 막고 노란 글씨 "수 14:30 초등 영어 수업 · 보기". 기간이 겹치는 다른 시즌도 함께 봄. 강사 겹침은 알리지 않음(세션 수업).
- **시즌 타임라인**: 12달 줄, 막대 = 시즌(준비 중 빗금 · 운영 중 연초록 · 끝남 회색), 겹치면 여러 줄 + 겹친 기간 빨간 빗금·노란 안내. 막대 누르기 = 그 시즌, 끝 끌기 = 기간, 몸통 끌기 = 옮기기, 빈 곳 끌기·[+ 새 시즌] = 새 시즌. 고치기 줄: 이름 · 시작 - 끝 · 상태 · 준비 중이면 [운영 시작] · [시즌 목록 →]. 고친 것은 작성 중 → 위 [저장 n]에 들어감.

## 3. 수업
- **블록**: 시간표 블록과 같은 모양. 지난·오늘 수업만 막대: 출석(출석 초록·보강 파랑·결석 빨강·미입력 빗금, "출석+보강/전체"), 과제(노션 과제상태 색: 완료·일부 완료·미제출), 평가 평균. 앞으로 수업 = 강사·인원. 수업 아직 없음 = 흐린 빗금. 휴강 = 회색 빗금 + 이름 줄긋기 + "휴강". 보강 = 같은 모양 + 이름 옆 파란 **"보강" 배지**(좁으면 "보"), 클래스 없으면 이름 "보강 MM.DD(요일)", 배지 생략.
- **명단** = 저장된 시간표 명단 + 그 수업 날짜에 수강 중인 학생(저장 안 한 학생·수강 시작 전 학생은 안 들어감).
- **[출결]** 상태: 블록을 눌러 고름. **[보강]** 상태: 빈 칸(블록 위도)을 끌어 새 보강.
- **수업 창**(정규·보강 같은 틀): 머리(이름 + **수업 구분 배지** 정규 초록·보강 파랑·휴강 노랑 + 자물쇠) → 탭 `[출결 n/m] [학습기록 n] [정보]`(학생·목록 창과 같이 "정보").
  - **출결**: 위 칸(출석·과제·평가), 머리 오른쪽 [모두 출석]/[모두 보강](미입력 학생만), 학생마다 정규 [출석|결석](🟢·🔴) / 보강 [보강|결석](🔵·🔴). 같은 칸 다시 누르면 미입력. 휴강이면 안내 + 단추 흐림.
  - **출결 줄 [한마디·메모]**: 학생 줄 오른쪽(출결 단추 앞) 말풍선 단추 28. 누르면 그 줄 아래에 선생님 한마디(학부모 일간 보고서에 보임) · 메모(내부용) 두 칸이 펼쳐짐(한 번에 한 학생). 적어 둔 줄은 단추가 진함. 빈 값만 넣으면 줄을 만들지 않음. 보강 수업도 같음. 노션 출석 `선생님 한마디`·`메모`에 대응(본문은 노션).
  - **[보고서] 탭(정규 수업, 탭 순서 출결 · 학습기록 · 보고서 · 정보)**: 일일 보고서. 제목 오른쪽 [전송 n] + 현황 "보냄 6/6 · 제외 1명". 학생 줄: 이름 · 상태 알약(보내기 전 / 보냄 / 제외 이유) · 보낸 줄의 [다시](보냄 표시를 풀어 그 학생만 다시 보냄) · 펼침 단추 → 그 학생에게 나갈 내용 미리보기(출석 → 학습 → 과제 검사 → 새 과제 → 평가 → 선생님 한마디). 제외 = 출결 미입력 · 결석 · 연락처 없음(결석 제외는 추정 — 매뉴얼에 없음). 탭 숫자 = 보낸 학생 수. 휴강 수업은 안내 글만. 저장 없이 바로 반영, Ctrl+Z.
  - **[정보] 수업 안내**: 수업 구분 아래 묶음. 제목 오른쪽 [전송 n](n = 아직 안 받은 학생, 0이면 꺼짐) + 현황 한 줄 "수업 일정 안내 · 안내 6/6 · 제외 1명". 종류는 수업 구분을 따름(정규 = 수업 일정 안내, 보강 = 보강 수업 안내, 휴강 = 휴강 안내). 제외 = 결석 학생(휴강 안내는 포함) · 학부모 연락처 없는 학생. 누르면 확인 창: 수업 이름·일시, 수업 안내 메모(50자, 비우면 없음), 보낼 학생 명단, 제외 이유 → [보내기]. 같은 일시로 이미 받은 학생은 건너뛰고, 수업 시간이 바뀌면 현황이 0부터 다시. 저장 없이 바로 반영(작성 중 아님), Ctrl+Z로 되돌림.
  - **수업 창 아래 [저장 n]·[되돌리기]**: 그 수업의 출결·날짜 바꿈 + 학습기록 + 과제검사로 고친 지난 과제 + 한마디·메모를 함께 센다. 안내 보낼 것이 없으면 묻지 않고 바로 저장.
  - **학습기록**: 묶음 둘. ① **과제검사** — 지난 수업에 낸 과제(마감 = 이 수업). 카드를 펴면 학생 줄만 나오고 제출·일부·미제출만 누름(입력칸·삭제 없음). 캘린더 블록의 과제 막대는 이 검사 결과. ② **학습기록** — 이 수업 기록 카드 여러 건. [학습기록 추가] 또는 기록이 없는 교재가 있으면 [진행 중 교재 n개로 만들기](교재마다 학습 한 건). 구분(학습·과제·평가) · 교재(그 클래스 진도교재) · 범위(숫자만, 단위는 교재가 붙임) · 내용. 과제 = 출제 내용만 적고 검사는 다음 수업에서. 평가 = 평가 구분(일일·주간·월간·단원·마무리·기타) + 전체 문항 + 학생마다 정답 문항 → 점수 = 정답 ÷ 전체 × 100(정답은 0~전체로 맞춤). 접으면 요약("제출 9 · 일부 2 · 미제출 1 / 12명", "평균 83점 (입력 12/12명)"). 본문(자료·사진·파일)은 [노션에서 본문 열기]. 고치면 작성 중 → 위 [저장] 수에 포함, 탭에 점. 삭제는 저장 때 반영, Ctrl+Z·모두 되돌리기로 복구. 보강 수업도 같음(과제검사는 없음). 노션 학습기록(학원)·학습활동(학원) DB에 대응. 아직 없음: 단원 입력, 마감 직접 고르기, 루틴 체크.
  - **정보**: 맨 위 **수업 구분** [정규|휴강] 또는 [보강|휴강] + [보강 추가] → 이 수업 날짜·시간(자물쇠 풀면 이 주 한 번만 옮김, 원래 자리 잔상 "여기서 옮김"(점선, 자리를 나누지 않고 뒤에 깔림 — 원래 자리 근처로 옮겨도 블록 하나로 보임, 정확히 원래 자리면 잔상 없이 원래 수업), [원래대로]) → 클래스(정규 보기만 / 보강 **클래스 목록**) → 학생(정규 같은 줄 모양으로 보기만 + [학생 추가] / 보강 **학생 고르기 목록**).
- **잠금 해제 ↔ 오른쪽 창은 따로**: 블록·수업 잠금을 풀어도 창이 열리거나 닫히지 않고, 창을 닫거나 다른 것을 골라도 잠금은 풀린 채(저장하면 다시 잠김).
- **수업 구분**: 시간표로 만든 수업 = 정규(정규↔휴강만), 직접 만든 수업 = 보강(보강↔휴강). 정규는 삭제 없음(Del = "[휴강]으로" 안내), 보강은 취소 = 휴강, 잘못 만든 것 = [보강 삭제]. 노션 `수업 구분` 단일 선택(정규·보강·휴강) 그대로, 휴강이 원래 무엇이었는지는 시간표 연결로 앎.
- **정규 [학생 추가]** = 시간표에 넣기: 학생 추가 창(언제부터 기본 = 오늘 이후 첫 수업일) → "시간표가 바뀌어요" 확인창([취소]면 고르던 창으로). 빼기는 시간표·수강 종료에서. 정규 클래스는 바꾸지 않음.
- **보강**: 클래스 없어도 됨(이름 "보강 MM.DD(요일)"), 클래스를 고르면 그 반 수강생만. 고르기 목록 묶음 = 선택된 학생 → 최근 결석(4주, 결석일 빨강) → 최근 휴강 클래스별([모두 넣기]) → 그 반 학생. [보강 추가] = 정규면 이 수업 결석 학생, 보강이면 같은 학생으로 새 보강. 만든 직후만 잠금 풀림. 보강 정보 카드 학생 줄에도 출결 아이콘.
- **옮기기·늘리기·붙여넣기**: 잠금 푼 수업·보강·만들기 전 점선 칸 모두 끌기·위아래 늘리기, 놓일 자리 점선 칸. 보강 Ctrl+C/V(같은 시간·학생, 출결 비움). 겹치는 학생만 알림.
- **할 일 탭**(수업을 안 골랐을 때): [미입력 n] [수업 없음 n](→ [이 주 수업 모두 만들기]) [보강 n](안에 [보강 대기 n][최근 결석], 7장 보강) + 막대 범례. 탭 이름은 짧게(320 폭 한 줄).
- **보강**(원본 매뉴얼 6-7) = 탭 [보강 대기 n] [최근 결석] (모듈 HP.wait).
  - 결석 상태: 판단 전 → 보강 필요 → 보강 예정(보강에 넣음) → 보강 완료(그 보강에 출석 = 목록에서 사라짐). 보강도 결석이면 다시 보강 필요. 보강 없음은 빠짐(사유는 적지 않아도 됨).
  - **보강 대기** = 등록(학생 + 클래스) 하나에 떨어진 카드 하나(한 학생이 두 클래스에서 빠지면 카드 두 장). 기간 제한 없음, 개수 = 카드 수. 카드 = [사람 아이콘 이름 학교 학년 ……… ● 클래스 · 숫자 배지(보강해야 할 횟수)]. 카드를 누르면 아래로 열려 카드와 이어진 한 덩어리(위 학생 줄 흰색 · 결석 줄 연한 색 40, 들여쓰기 + 달력 아이콘): 결석일(요일) · n일 전 ……… 상태 글 + 상태 아이콘.
  - **상태 아이콘**(두 탭 같음, 선 아이콘 24): 보강 필요 = 갈색 시계 · 보강 없음 = 옅은 회색 x(날짜 취소선) · 보강 예정 = 달력("보강 예정 · 11.14(토)") · 보강 완료 = 체크. 필요 ↔ 없음은 아이콘을 눌러 바꿈. 보강 없음으로 바꾸면 그 줄 아래 사유 칸(32, 커서 바로).
  - **최근 결석** = 기간(기본 4주, 2·4·8·12주) 결석을 주차 구역(월~일)으로 묶은 붙은 목록(끌 수 없음). 줄 = 이름 · ● 클래스 ……… 날짜 · 상태 아이콘. 실수로 보강 없음 한 것을 여기서 되돌림(아이콘에 마우스를 올리면 사유).
  - 보강 대기 카드를 끌어 **만들어 둔 보강 블록에만** 놓기(그 클래스 보강·클래스 없음 보강만) → 그 보강에 학생 출석이 생기고 그 학생의 **가장 오래된 보강 필요 결석**과 연결(보강 날 이전, 클래스 보강이면 그 클래스 학생·결석만). 보강 필요 결석이 없으면 안 넣고 "결석마다 필요·없음을 먼저 골라 주세요". 정규 수업·휴강 보강·빈 칸은 안 받음.
  - 아래 [보강 추가] = 학생·클래스 없이 보강 모드로(빈 칸을 끌어 시간) — 보강은 아무도 없이 만들 수 있고 학생은 나중에 끌어 넣음.
  - **결석 ↔ 보강 1:1**(원본 출석 `보강 출석`·`기존 결석` — 보강 수업 안내 알림톡의 "📅 기존 결석" 줄이 이 값). 다른 길(학생 고르기 등)로 넣은 학생도 가장 오래된 보강 필요 결석과 이어짐. 보강에서 빼거나 보강 삭제·휴강·그 결석을 보강 없음으로 바꾸면 연결이 풀림. 화면에 연결을 따로 표시하지 않음.
  - 수업 창 출결 탭: 결석 학생 옆 회색 작은 글씨 "보강 없음 · 사유" / "보강 예정" / "보강 완료".
  - 보강 학생 고르기 목록은 선택된 학생 다음에 [보강 대기] 묶음, 그다음 최근 결석·최근 휴강.
- **사이드바 "수업"**: 수업 묶음 맨 아래(클래스·수강·시간표·수업). 누르면 지금 시간표 탭을 수업 보기로 바꿈(새 탭 아님, Ctrl·가운데 클릭은 새 탭). 오른쪽 창은 이전 상태(띄움·고정·닫힘) 그대로 — 열려 있으면 내용만 할 일로, 닫혀 있으면 닫힌 채([창] 배지로 할 일 수). 탭 이름 "수업 · 시즌". 노란 배지 = 이 주 출결 미입력 + 보강 대기, 마우스를 올리면 나눠 보임. 오른쪽 창 단추 배지 = 할 일 세 탭 합.

## 4. 학생
- 열(기본 순서 = 정보 입력 순서): 등록상태 · 문의일 · 이름 · 학교 · 학년 · 생년월일 · 성별 · 주소 · 학생/어머니/아버지/기타 연락처 · 학생과 관계 · 우선 연락처(작은 글씨 대상 + 번호, 번호가 없으면 빨간 "번호 없음") · 등록 클래스(클래스 색 칩) · 등록일 · 종료일. 열 너비는 글자에 맞춘 고정 폭(상태 거르기·창 고정과 상관없이 같은 모양, 넘치면 가로 스크롤), 칸 안쪽 좌우 12.
- 편집 중 표시: 제목 줄·위 줄 바탕 옅은 노랑(#FFF8E1) + 위 줄 아래 노란 선 3 + 표 머리 노랑 + 제목 옆 진한 노란 칩 + 표 아래 가운데 안내 바 "표 편집 중 · 칸을 눌러 바로 고쳐요 (작게 Enter 아래 · Tab 옆 · Esc 취소) · 고친 것 n명"(단추 없음, 들어갈 때 알림은 안 띄움 — 바와 겹치는 안내라서, 다른 알림은 바 위로). 머리의 정렬·거르기 표시는 10px, 열 아이콘(14)과 세로 가운데를 맞춤.
- 편집 모드에서는 열 머리를 끌어 옮김(머리 앞에 잡는 표시, 놓을 자리 진한 세로 선). 평소에는 못 끔.
- 편집 모드에서 머리 오른쪽 끝(세로 선 손잡이)을 끌면 열 너비(48~480, 기기에 저장), 두 번 누르면 기본 너비.
- 편집 모드 단추 = [열 정리] [취소] [완료](아이콘만). [완료] = 편집만 끝, 고친 줄은 작성 중으로 남아 위 [저장 n]으로 저장(모든 표 화면 같음). [취소] = 고친 것이 있으면 "편집을 취소해요 · 이번에 고친 학생 n명은 원래대로 돌아가요" [계속 편집][편집 취소].
- 표 모양(열 순서·숨김·너비)은 **거르기 탭마다 따로**. 손대지 않은 탭은 "전체" 탭 모양을 따르고, [열 정리]에 "○○ 탭만"·"지금은 전체 탭 모양" 표시, [전체 탭 모양으로](전체 탭에서는 [기본으로]). 시제품은 이 기기 저장, 원본은 서버(13장).
- **[열 정리]**(표 편집 모드에서, Feather columns): 열 목록을 끌어 순서 바꾸기 · 눈 아이콘으로 숨기기/보이기 · [기본으로]. 기기에 저장. 숨긴 열이 있으면 [표 편집]·[열 정리] 단추에 "n 숨김".
- **머리 누르기** = 오름차순·내림차순 정렬 · 거르기(값이 정해진 열 = 값 목록 체크와 개수, 나머지 = 포함하는 글자) · 이 열 숨기기. 정렬·거르기가 걸리면 머리 글자 진하게 + 아이콘, 제목 줄 옆 "거르기 칩 [풀기]". 엑셀 "지금 보는 목록"도 같은 거르기.
- 찾기 칸은 한글 조합 중에 다시 그리지 않음(조합이 끝나면 거름).
- 틀: 기준 2~5장 그대로. D1 = 등록상태 탭(전체·등록 중·등록 전·신규문의·보류·종료, 수) · D2 = 찾기.
- **등록상태는 자동**(원본 수식): 등록 보류 → 등록 없음 = 신규문의 → 수강 중 등록이 하나라도 = 등록 중 → 가장 최근 등록이 끝남 = 종료 / 시작 전 = 등록 전. 손으로 바꾸는 것은 **[등록 보류]** 하나. 재원·휴원·퇴원 없음(학생 휴원은 보류 — 필요하면 등록에 `휴원 기간` 설계).
- **표는 평소 보기만, [표 편집] 모드에서만 칸 바로 고치기.** 평소: 칸 테두리·글자 커서 없음, 줄을 누르면 그 학생 오른쪽 창, 고른 줄 = 줄 바탕 + 왼쪽 진한 띠, 고친 학생 = 줄 왼쪽 노란 띠. [표 편집]을 누르면 [열 정리][취소][완료]로 바뀌고 제목 옆 "표 편집 중" 표시. 편집 모드: 고칠 수 있는 칸(문의일시·이름·학교·학년·생년월일·성별·주소·연락처·학생과 관계·우선 연락처 = 대상 고르기 학생·어머니·아버지·기타 보호자)에 마우스를 올리면 칸 테두리, 누르면 칸 안 입력(학교·학년·성별은 같은 드롭다운, 문의일시·생년월일은 날짜 칸 공통 = 직접 입력 + 작은 달력), Enter 아래 줄 · Tab 옆 칸 · Esc 취소, 고친 칸 노란 바탕. 등록상태·등록 클래스·등록일·종료일은 표에서 못 고침(누르면 창).
- **[엑셀 ▾]**(D3, Feather 표 아이콘 + "엑셀"):
  - 내려받기: 상태 거르기·찾기가 걸려 있으면 [지금 보는 목록만 받기 n명](거른 조건 표시)과 [전체 학생 받기 n명] 둘, 없으면 [엑셀로 내려받기] 하나. 칸 = 이름·학교·학년·등록상태·문의일시·학생/어머니/아버지/기타 연락처·학생과 관계·등록 클래스·메모. 파일 맨 위에 "내려받은 날 · 거른 조건 · n명". 파일 = xlsx(제목·안내 줄, 갈색 머리 줄, 학년 칩 색, 상태 글자색, 우선 연락처 번호 없으면 빨강, 줄무늬, 이름·머리 틀 고정, 칸마다 거르기). 엑셀 도구(ExcelJS 4.4.0, MIT)는 `vendor/`에 같이 둠 — 외부 서버 없이 늘 xlsx(못 불러오면 CSV).
  - 엑셀로 한번에 올리기: 창에 ① [양식 내려받기] ② [파일 올리기]. 양식 = 첫 시트 "작성 안내" + "학생 입력"(이름 *, 회색 예시 줄, 학년·관계·우선 연락 목록 고르기). 올리기는 .xlsx 그대로(시트 "학생 입력" 또는 칸 이름 "이름"이 있는 시트), .csv도 됨, 옛 .xls는 안내. 칸은 순서가 아니라 칸 이름으로 읽음(받은 명단을 그대로 올려도 됨). 이름·연락처가 같은 학생은 건너뜀. 올린 학생은 신규문의·작성 중 → 위 [저장]. 파일 이름은 영문.
- 이름은 창 머리의 이름을 눌러 바로 고침(Enter·Esc). 빠른 등록도 같은 자리에 이름 칸.
- 오른쪽 창 = 시간표 창과 같은 틀: 붙는 머리(이름 + 상태 알약 + (?) 이유 / 학교·학년·문의·등록·종료 / 주간 시간표 ↗ · 수강 ↗) · 탭 [정보 | 등록 n | 일정 | 성적](일정·성적 준비 중, 처음은 정보) · 묶음 제목 15/700 + 아이콘 · 라벨은 칸 위(칸 40) · 아래 동작 줄 [삭제] … [↺][저장 n](이 학생만). 등록은 등록 카드(아래).
  - 입력 칸은 입력칸 모듈(11장): 왼쪽 아이콘 + 왼쪽 정렬(날짜 "2026.08.29", 누르면 달력). 메모는 아이콘·x 없이 칸 전체 폭, 칸 모서리로 늘렸다 줄였다.
  - 정보 탭: 문의(문의일시 한 줄 / 문의 경로 | 개인정보 동의 / 희망 시작일 | 등록 보류 / 메모 = 신청서 "추가 전달사항"과 같은 칸, 왼쪽 정렬) → 기본정보(학교 | 학년 / 성별 | 생년월일 / 주소(긴 글, 왼쪽 정렬) / 형제자매 한 줄: 칸 = "형제·자매 선택"(재원·종료·문의 학생 모두 고를 수 있음)(칸 폭 학생 목록), 고른 학생은 칸 아래 같은 목록 줄) → 연락처(학생 · 어머니·아버지 [우선] · 구분선 · 기타 [우선] · 학생과 관계). 학교·학년·문의 경로는 같은 드롭다운(찾기·↑↓·Enter). 학교·문의 경로는 목록에 없으면 찾기 칸 글자로 [+ 새 학교]/[+ 새 경로] — 새 경로는 저장 때 노션 학생 DB [문의 경로] 선택지에도 생김(원본: 노션 API는 없는 선택지 값을 넣으면 선택지를 만듦, 앱 목록은 노션 선택지를 읽어 씀). 스위치는 40 높이 칸 안 오른쪽.
  - 창 3단계(시간표와 같음): [창]·`]` = 띄우기(표 위에 뜸) → 고정(표 옆, 표가 좁아짐) → 닫기. 띄운 창은 바깥·Esc로 닫히고, 고정은 Esc로 안 닫힘. 폭 320~600(다른 창과 같음).
- **학생 오른쪽 창 기본 = 할 일**(학생을 안 고른 채 창이 열려 있을 때, [창]·`]`도 할 일부터). 탭 [신규 문의 n][정보 누락 n][등록 전 n], 사이드바 학생 숫자 = 세 탭 합.
  - 신규 문의 = 등록이 없는 학생, 오래된 문의 위, 14일 넘으면 노란 글씨("문의 n일 전"), 아래 줄 문의일·문의 경로·희망 시작일. 누르면 그 학생 창(정보 탭).
  - 정보 누락 = 이름·학년·학교·연락처 중 빈 것이 있는 학생(연락처는 학생·어머니·아버지·기타가 하나도 없을 때, 종료 학생 제외). 오른쪽 노란 글씨 = 빠진 것, 이름이 없으면 "(이름 없음)". 누르면 학생 창 + 빠진 첫 칸에 커서(노란 테두리 잠깐).
  - 등록 전 = 가장 최근 등록이 아직 시작 전. 누르면 학생 창 [등록] 탭.
  - 할 일에서 연 학생 창은 위에 [‹ 할 일], Esc도 할 일로. 할 일에서 Esc(띄운 창)·바깥 누름 = 닫기. 다 처리하면 "할 일이 없어요". 아래 [학생 추가].
- **새 학생 = 같은 학생 창.** 위 줄·할 일의 [학생 추가] → 빈 학생 창(같은 머리·탭·칸). [학생 추가] 누름은 "바깥 누름"이 아님(띄운 창이 닫히지 않음). 이름을 입력하기 전엔 표에 없고(안내 "이름을 먼저 입력해 주세요"), 입력하면 신규문의(작성 중, 원본 흐름 4-2 → 5-1). 아래 [저장] 하나 — 저장하면 그 학생 창으로 남고, 등록은 직접 [등록] 탭으로.
- 등록 탭 = **등록 카드**(등록 하나 = 카드 하나, 정보 + 입력). 제목 줄 "등록 n"(보류 중이면 "등록 보류 중 — 정보 탭에서 바꿔요") → 카드들(수강 중·수강 대기 위, 종료는 흐리게 맨 아래) → 점선 빈 카드 [+ 등록 추가].
  - 카드: 색 점 · 클래스 이름 + (작성 중) + 상태 알약(날짜로 자동: 수강 대기·수강 중·수강 종료) / 담당 강사 · 과목 · 요일 / 등록일 · 종료일(바로 입력, 날짜 칸 공통) / 시간표 · 교재 = 클래스 칸과 같은 크기의 고르기 칸(지금 값이 칸 안에, 비면 "시간표 선택"·"교재 선택").
  - 수강 종료 = 종료일 입력(다음 날부터 수업 명단에서 빠짐). 따로 [수강 종료] 창 없음. 등록일 > 종료일은 막음.
  - [등록 추가] → 그 자리에 입력 카드(✕ = 버림): 클래스 칸("클래스 선택", 누르면 칸 폭 드롭다운 = 공통 클래스 목록) · 등록일(희망 시작일, 지났으면 오늘) · 종료일(비움). 클래스를 고르면 바로 작성 중 카드가 되고 그 클래스 이번 시즌 시간표 전체에 들어감. 같은 클래스에 끝나지 않은 등록이 있으면 막음.
  - 시간표 칸 → 칸 폭 목록: 그 클래스 이번 시즌 시간표(찾기, 요일·시간·강사·인원), 다닐 요일 체크 → 아래 "언제부터"(기본 오늘, 시작 전 등록이면 등록일) → [적용] = 시간표 작성 중(시간표 [저장]에서 반영, 시간표 학생 추가와 같은 규칙). 교재 칸 → 칸 폭 목록: 그 클래스 교재 먼저, 다른 교재, 찾기, 여러 권 체크 → [적용](등록 작성 중). 자세한 수강 정보(할인·수강료 등)는 수강 화면에서.
  - 고친 카드 = 작성 중(테두리 진하게 + "작성 중" 알약), 창 아래 [저장 n]에 들어감, [↺]로 되돌림(새 카드는 지워짐).
- **행 삭제**: 줄 끝 휴지통(마우스를 올리면 보임) · 줄을 고르고 Delete · 창 아래 [삭제]. 바로 지우지 않고 그 줄 그대로 "삭제 예정"(상태 칸 빨간 알약, 나머지 흐리게·줄긋기, 눌러도 창 안 열림) + **휴지통 자리에 [↺ 되살리기]** → [저장] 때 지움(그 학생 등록·시간표 연결도). Ctrl+Z로도 되돌림. 휴지통·되살리기 칸은 표가 넓어도 화면 오른쪽 끝에 붙어 늘 보임.

## 5. 과목·라이브러리
- 메뉴 "학습" 묶음: **과목**(노션 과목(학원) DB) · **라이브러리**(노션 라이브러리(학원) DB와 같은 이름, 안의 한 줄은 "교재"). 둘 다 표 화면 공통 틀(11장 표).
- 과목 표 = 과목 · 영역 · 학년(4개 넘으면 "중1-고1") · 학교(초등·중등·고등) · 교재 n권 · 학생이 쓰는 교재 n권. 거르기 = 교재 없는 과목 · 학년 빈칸 · 예체능(영역 없음). 창 = 과목 이름 · 노션 이모지(앱에서는 안 보임) · 영역(비우면 예체능) · 학년(여러 개) · 비고 + "이 과목 교재" 목록([교재 추가]).
- 라이브러리 표 = 교재명 · 과목 · 구분 · 출판사 · 분량("180쪽"·"24 UNIT"·"8차시" — 전체 분량 + 진도 단위) · 가격 · 쓰는 학생 n명 · 사용. 거르기 = 사용 중(처음 켜짐) · 프로그램 · 가격 없음. 창 = 노션 라이브러리 칸(북커버·PDF·단원목록·웹훅 정보 빼고) + "쓰는 곳"(클래스별 학생).
- 등록 카드 [교재] 칸 = 라이브러리의 "사용 중" 교재, 이 클래스 과목(영역) 교재 먼저.
- 이모지는 앱 화면에 쓰지 않음(노션 저장용 칸만).

## 6. 단축키·취소
- **날짜 칸**(모든 화면): 직접 입력(2026.11.11 · 20261111 · 11.11, 시각 있는 칸은 2026.11.11 14:30) + 누르면 작은 달력(글자 칸에 포커스 유지, [오늘], 범위 밖 흐림). Enter 확정·Esc 취소, 틀린 값은 안내 후 되돌림. 빈 칸 안내 글 = "YYYY.MM.DD"(예시 날짜는 값처럼 보여서 쓰지 않음). **달력은 모두 월요일 시작**(시간표 주와 같음), 토 파랑·일 빨강, 칸 왼쪽에 맞춰 열림.
- Esc = **떠 있는 것부터 하나씩 닫음**(목록·색판·달력·시간 휠 → 그것만) → 취소(만드는 중인 새 시간표·보강·학생 고르기 → 버림) → [추가]·[보강] 모드 끝 → 그 밖엔 창 닫기, 고정 창은 안 닫힘. Delete = 같은 취소(글자 칸에 글자가 있으면 글자만), 고른 보강·삭제 가능한 시간표는 삭제.
- `[` = 왼쪽 메뉴 열고 닫기, `]` = 오른쪽 창 [창] 단추와 같이 펼치기 → 고정 → 닫기. 글자 칸에 있거나 확인 창이 떠 있으면 안 함. 단추에 마우스를 올리면 단축키가 보임.
- **이름·아이콘 구분**: 실행 취소(Ctrl+Z, ↰ 꺾인 화살표) · 다시 실행(Ctrl+Y, ↱) = 한 단계씩. 되돌리기(↺ 원 화살표) = 저장 상태로(위 줄 = 모두, 창 아래 = 그 클래스·수업·학생). 칸에 입력하던 중에 [↰]를 누르면 그 입력을 먼저 기록하고 실행 취소(= 방금 입력한 것이 취소됨). [↰]·[↱]·[↺]를 눌러도 띄운 오른쪽 창은 닫히지 않음. + / − 보기 크기(Ctrl·Alt+휠). Ctrl+C/V = 시간표·보강 복사. Ctrl+Enter = 창 [저장].

| **학생 고르기 목록** | 학생 칸(검색창)을 누르면 칸 폭 목록: 비었으면 묶음(머리 오른쪽 [모두 넣기/빼기]), 글자를 넣으면 묶음 결과 + "그 밖의 학생". 줄 = 고르기 목록 줄(11장) — 줄을 누르면 넣기·빼기, 넣은 줄 ✓(마우스를 올리면 x), 안 넣은 줄은 마우스를 올리면 + / 아래 [다른 학생 찾기] | 시간표 학생 탭, 보강. 정규 수업 정보는 같은 줄(체크 자리 비움) 보기만 |
| **학생 추가 창**(따로 뜨는 창) | 제목 "학생 추가 — 클래스 요일 시간 시간표" · (정규) 언제부터 · 이름·학교 찾기 · 학년(드롭다운+검색, 초→중→고) · 범위(전체/○○ 수강생/다른 학생) · "이 시간 비어 있는 학생만" · 같은 줄 모양 목록 · "n명 선택 [취소][n명 넣기]" | 시간표 [다른 학생 추가]·[클래스에 학생 추가], 정규 [학생 추가], 보강 [다른 학생 추가] |
- **칸 = 검색창**(창 안 클래스·학생 칸 공통, 모듈 HP.cls·HP.stu): 칸은 돋보기 + "클래스 검색"·"학생 검색 · 이름·학교"(화살표 없음). 누르면 바로 글자 입력 + 칸 폭 목록(한 번에 하나, 바깥 누름·빈 칸 Esc = 닫힘). **클래스**는 고르면 칸이 카드로 바뀜([색 동그라미 = 아이콘(누르면 색판) · 이름 ……… x], 카드를 누르면 다시 검색, x·Delete = 비우기, 보강은 "클래스 없음"도 같은 카드). **학생**은 고른 학생이 칸 아래 **붙은 목록**으로 쌓임(줄에 마우스를 올리면 x, Delete = 빼기), 구역이 있으면 구역 머리(시간표 = [이 클래스 학생][다른 학생 — 넣으면 수강도 함께 생겨요]). 쓰는 곳: 새 시간표 [클래스]·[학생], 새 보강·만든 보강 [수업 정보]·[학생 편집], 정규 수업 [학생 추가], 등록 카드 클래스·형제자매.
- **찾기는 따로 뜨는 창**: 열린 목록 맨 아래 왼쪽 돋보기 줄 — 클래스 목록 = [종료된 클래스 찾기](창: 찾기 칸·강사 거르기·종료일, 고르면 "다시 열까요?" 뒤 그 칸에 들어감, 시간표는 시즌 밖 클래스도 함께), 학생 목록 = [다른 학생 찾기](학생 추가 창). 목록 안에서 화면을 바꾸지 않음. 시간표 클래스 전체 표 아래 [클래스에 학생 추가]는 없음(다른 학생은 위 칸·찾기 창으로).
- 칸 폭 목록은 아래 자리가 모자랄 때만 위로 열고, 실제 높이로 칸에 붙음(간격 4).
- 좁은 칸 하나에서 고를 때만 **드롭다운+검색 한 칸**(위 찾기, 학년 등). 눌러서 작아지는 select 금지.

### 모듈을 화면에 붙이는 기준
- **클래스 없음**은 보강 칸에서만 고를 수 있음(시간표·등록 카드는 클래스가 꼭 있어야 함).
- **학생 칸이 비었을 때 묶음**: 보강 = 보강 대기 · 최근 결석 / 시간표 = 이 클래스 학생 / 형제자매 = 최근 등록·문의 학생.
- **보강 대기 카드를 놓는 곳**: 그 클래스 보강 블록과 클래스 없음 보강 블록만. 다른 클래스 보강 블록에 놓으면 넣지 않고 안내만.
- **보강 없음 사유**는 적지 않아도 됨(비워도 저장).
- **클래스 색 = 저장용**: 노션 클래스 DB [색](선택 칸, 노션 10색: 빨강·주황·노랑·초록·파랑·보라·분홍·갈색·회색·기본) + [색 코드](글자 칸, 무지개 동그라미로 직접 고른 색만 "#RRGGBB", 이때 [색]엔 가장 가까운 색). 앱은 색 코드가 있으면 그 색, 없으면 [색]. **블록 바탕·왼쪽 띠·글자·표 색 점·색판이 모두 이 한 색에서 나옴**(바탕 18%, 띠 70%, 글자 = 그 색 + 진한 갈색) — 옛 12색표 없음. 새 클래스는 운영 중인 다른 클래스가 안 쓰는 노션 색(기본 뺀 9색)부터, 다 쓰면 색 코드. 클래스 창 [색] 칸(구분 아래), 클래스 표 이름 앞 색 점. 노션 화면의 클래스 구분은 지금처럼 이모지(필요하면 나중에 바꿈). 클래스 없는 보강은 보강 색을 따로 둠.

### 할 일 카드 여러 명 고르기
- 카드 누름 = 선택(연갈색), Shift = 범위, Space·Shift+↑↓. 위에 "n명 선택 · 시간표에 끌어 놓기 [선택 해제]", 묶음 머리 [모두 선택]/[선택 해제].
- 고른 카드 하나를 끌면 모두 함께(끄는 모양 = 그 카드 그대로, 여러 장이면 오른쪽 위 숫자). 놓을 수 있는 블록 = 모두의 클래스 조건을 만족하는 곳, 이미 있거나 같은 시간 수업이 있는 학생은 빼고 넣고 알림에 "못 넣음".
- 시간표 할 일 탭 = [시간표 없음 n][점검 n]([클래스 없음] 탭 없음). 시간표 없음 = 클래스별 묶음(카드 = 그 수강, 수강 시작일로 급한 순 + 왼쪽 띠) + **맨 아래 "클래스 없음" 묶음**(아직 클래스가 없는 학생, 시간표에 놓으면 그 클래스 수강도 생김). 묶음 머리 [모두 선택]·[선택 해제].
- 학생 화면 [클래스 입히기]로 온 학생 하나는 그 학생 클래스 고르기 창(할 일 탭과 따로). 보강 대기 = 카드 한 장씩(그 클래스 보강·클래스 없음 보강 블록에만).

### 학생 정보 — 상황별로 보이는 것
- 이름 옆은 늘 **학교·학년**(같은 이름 구분). 오른쪽 정보는 상황 정보: **어디에 넣을지 정할 때 = 등록 클래스**, 왜 넣는지 = 결석·겹침, 이미 반 안이면 없음.
- 클래스 없음: 없음 · 시간표 없음: 그 밖의 클래스(묶음 머리가 클래스) + 급한 정도는 카드 왼쪽 띠 · 보강 대기: ● 클래스 + 숫자 배지(보강해야 할 횟수) · 보강 학생 고르기: 결석(빨강)/등록 클래스/같은 시간 수업(노랑) · 학생 추가 검색: 등록 클래스 · 출결·정보 카드: 없음. 한 줄 카드에서 결석·안내 글은 마우스를 올리면.
- 등록 클래스 중 그 시간에 겹치는 반은 그 반 이름만 노랑 "중2 수학A 16:00 겹침"으로 바꿔 한 번만. 다니는 반이 아닌 수업(보강 등)과 겹칠 때만 노란 글을 따로 붙임.

### 시험 · 성적
- **시험 표**: `응시 학생` = 등록한 수/대상 수("6/6명"), `평균` = 점수를 넣은 학생 평균. 창 [정보]에 응시 인원(학교 전체, 백분율 계산용).
- **시험 창 [성적] 탭**: 제목 오른쪽 **[응시학생 등록 n]** = 같은 학년(학교를 골랐으면 그 학교)의 수강 중 학생마다 성적 줄을 만듦(이미 있는 학생은 건너뜀, 0이면 꺼짐, 바로 반영·Ctrl+Z). 현황 한 줄 "미응시 n명" / "전원 응시 · 평균 82.5점 (입력 5/6명)". 학생 줄 44: 이름 · 점수 칸 · 등수 칸 · 백분율(등수 ÷ 응시 인원 × 100). 값을 넣으면 그 줄 작성 중(이름 옆 노란 점) → 위 [저장]. Tab으로 다음 칸으로 넘어가도 커서가 유지됨. 시험지·성적표 파일은 노션에서.
- **학생 창 [성적] 탭**: 그 학생이 응시한 시험 줄(시험 · 과목 / 시험일 · 점수 · 등수 · 백분율) → 누르면 시험 화면 [성적] 탭.

### 저장 창(위 [저장])
- 첫 줄 요약은 있는 것만: "시간표 2개 · 수업 1개 · 그 밖에 작성 중 3개" / 다른 것이 없으면 "작성 중 1개". 그 아래 작성 중인 줄 이름(10건까지) → 수업 목록 → 안내 묻기. 도움말: 한 번에 노션에 보냄 · 노션에서 바뀐 줄은 저장 전에 알림 · 수업 한 개만 보내려면 수업 창 [저장].

### 진도교재 · 클래스 창 [교재] 탭
- **진도교재 표**: `최근 학습 범위`·`진행도`는 계산 값(고치는 칸 없음) — 수업 창 [학습기록]에서 그 교재로 적은 가장 최근 학습 기록의 범위, 진행도 = 범위 끝 숫자 ÷ 라이브러리 전체 분량. 보강 수업 기록은 뺀다. 학습기록이 없는 교재는 넣어 둔 값을 그대로 보여 준다.
- **진도교재 창**: [기본] 교재·클래스·진도방식·학생(개별)·진행상태·주제·수료일 → [진도] 묶음(최근 학습 범위 · 진행도 · 전체 분량 + 최근 기록 6줄: 날짜·구분·범위·요약). 진행 중이면 묶음 제목 오른쪽 **[수료]** → 확인 창 → 진행상태 완료 · 수료일 오늘 · 학습 보고서에 수료 발송함 1건(기간 = 첫 학습일~오늘, 대상 = 반 전체는 수강 중 학생 수, 개별은 1명. 학생이 없으면 안 만듦, 같은 교재로 두 번 만들지 않음). 알림톡은 학습 보고서 [일괄 전송] 때.
- **수강 창 [교재] 탭**: 이 학생이 쓰는 교재(반별 + 이 학생 개별) 줄 → 누르면 진도교재 화면. 개별 진도 기준 교재가 있고 이 학생 것이 없으면 **[교재 생성 n]**(바로 만듦, Ctrl+Z).
- **클래스 창 [교재] 탭**: 그 클래스 진도교재 줄(교재 · 진행상태 · 최근 범위 · 진행도 · 개별이면 학생) → 누르면 진도교재 화면. **[교재 추가]** = 그 클래스로 새 줄(진행 중인 교재가 있으면 "다음 교재", 없으면 "진행 중")을 만들고 진도교재 화면에서 연다. **[교재 생성 n]** = 개별 진도 기준 교재(학생 비움)를 수강 중 학생마다 복사(이미 있는 학생 건너뜀, n = 만들 수, 0이면 단추 없음), 확인 창에 명단.

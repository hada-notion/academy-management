0. 창 뼈대

모든 오른쪽 창은 이 네 칸으로만 생성한다. 높이가 정해진 칸(머리 3줄·탭 바·아래 단추)은 창마다 같은 자리 — 탭을 바꿔도, 다른 화면으로 가도 위치가 움직이지 않는다.

머리 — 3줄 고정이름 + 상태 배지 / 정보 + 기타 배지 / 바로 가기
탭 바 — 1줄 고정탭이 없는 창도 '정보' 하나
내용 — 상자를 위에서 아래로상자 = 제목 + (?) + 오른쪽 링크 + [칸 묶음 · 줄 목록 · 카드 · 미니 부품]
아래 단추 — 1줄 고정삭제 ……… 되돌리기 · ○○ 저장
창 = {
  head:  { name, dot, status:[{t,tone}], info:[…], badges:[…], links:[{t}] },
  tabs:  [{ id, label, n }],  tab: "info",
  boxes: [{ title, help, right, fields | rows | cards | mini | body }],
  foot:  { del, undo, save: "○○ 저장", saveOn }
}
선택 전 = { todo: { groups:[{name, why, rows}], summary:[[이름, 값]], list } }

아이콘 규칙 — 규칙 파일(hada-rules.js) 한 곳

아래 표는 규칙 파일을 그대로 읽어 그려요. 메뉴 · 창 제목 · 표 열 머리 · 오른쪽 창 칸이 모두 이 규칙을 써요. 아이콘을 바꾸려면 규칙 파일 한 줄만 고쳐요. 순서: ① 칸 이름 예외 → ② 메뉴와 연결된 칸 = 그 메뉴 아이콘 → ③ 칸 종류 → ④ 고르기 기본 ⌄.

1. 머리

1줄 = 무엇인지(이름 + 상태 배지 + (?)), 2줄 = 정보 글(종류 · 날짜 · 학생·학교) + 기타 배지(정규·보강·학년), 3줄 = 바로 가기. 줄마다 한 줄, 넘치면 …. 배지는 모두 둥근 알약 20px.

2. 탭 바

숫자는 이름 뒤 작게. 못 여는 탭은 흐리게. 탭이 없는 창도 '정보' 하나를 둬서 높이를 맞춘다.

3. 상자

제목 · (?) 도움말 · 오른쪽 끝 링크나 작은 단추. 같은 일을 하는 상자는 화면이 달라도 같은 이름(예: 시간표).

4. 칸

입력칸 모듈(field.js) 그대로 — 글 · 날짜 · 고르기 · 숫자 · 전화 · 긴 글 · 나눔 단추 · 켜기/끄기 · 색. 알림톡으로 나가는 칸은 이름 옆 (?)에 어디로 나가는지.

5. 날짜·시각 한 줄

시작–끝 세트는 이름 하나, 두 칸 사이 '-', 요일 없음(입력칸 모듈 dateRange · timeRange).

6. 줄 목록

이름 ……… 정보 · 꼬리표 ›. 누르면 그 항목 화면. 색 점은 클래스·시즌처럼 색이 있는 것만.

7. 카드

줄보다 정보가 많을 때(등록 카드, 학생 카드, 교재 카드). 지금은 화면마다 따로 — 공통 카드 하나로 모을 대상.

8. 미니 부품

상자 안에 들어가는 작은 그림: 주간 시간표 · 달 캘린더(학생 리포트 모양) · 그래프.

9. 선택 전 = 할 일 창

줄을 안 골랐을 때. 할 일 갈래 탭 · 이유 한 줄 · 줄(누르면 그 줄 열림) · 요약 숫자 · (있으면) 목록.

10. 아래 단추

삭제(왼쪽) ……… 되돌리기 · ○○ 저장(오른쪽). 저장은 그 줄만, 고친 게 없으면 흐림. 시간표·수업도 '수업 저장'·'시간표 저장'처럼 이름을 붙인다.

# 오른쪽 창의 기본 상태 조사와 채울 내용 제안 (233판 기준)

대표 요청(261114, 후순위): 줄을 고르지 않았을 때 오른쪽 창이 비어 있는 화면이 많다. 화면마다 지금 무엇이 보이는지 정리하고, 빈 곳에는 "기본 상태"나 "해야 할 일"을 보여 주도록 제안한다.

- 조사 방법: 메뉴의 모든 화면을 줄을 고르지 않은 채 열고 오른쪽 창의 글을 뽑았다(도구 `hada-ui-tests/x/panel-survey.cjs`).
- 결과: 25개 화면 중 **할 일이 나오는 곳 2개**(학생 · 시간표), **빈 안내 글만 나오는 곳 19개**, **창이 없는 곳 4개**(오늘 · 수업 · 학원 정보 · 관리자 설정).

## 나. 채울 내용 제안

원칙: 학생·시간표 화면과 같은 모양의 **[할 일]** 창을 쓴다. 탭 = 할 일의 갈래(숫자 붙음), 줄 = 누르면 그 줄이 열림. 할 일이 하나도 없으면 "지금 할 일이 없어요"와 요약 숫자 2-3개만 보여 준다. 위 줄의 거르기 알약과 같은 조건을 쓰되, 창에서는 "왜 해야 하는지"와 다음 단추를 같이 준다.

| 화면 | 할 일 탭(안) | 할 일이 없을 때 요약 |
|---|---|---|
| 일정 | 오늘·이번 주 일정 / 지난 일정 중 완료 안 된 것 / 학부모 공개인데 안내 전 | 이번 달 일정 수 · 휴원일 |
| 가정통신문 | 보내기 전 / 전달사항 빈 것 | 이번 달 보낸 수 |
| 선생님 | 맡은 클래스 없는 선생님 / 연락처 빈칸 | 선생님 수 · 요일별 출근 |
| 학습 보고서 | 보내기 전 / 한마디 빈 것 | 이번 주 보고서 수 · 보낸 비율 |
| 학교 | 학교 코드 없음 / 학사일정 가져온 지 오래됨 | 학교 수 · 학생 많은 순 3곳 |
| 학교 [학년] | — | 켜진 학년 · 학년별 학생 수 막대 |
| 시험 | 범위 빈칸 / 응시학생 등록 안 함 / 지난 시험 중 점수 안 넣음 | 다가오는 시험 3건(D-며칠) |
| 시즌 | 준비 중인 시즌(운영 시작 필요) / 곧 끝나는 시즌(다음 시즌 없음) | 지금 시즌 · 남은 날 · 시간표 수 |
| 클래스 | 시간표 없음 / 학생 없음 / 종강 임박 / 진행 중 진도 없음 | 운영 중 클래스 수 · 학생 수 |
| 등록 | 시간표 없는 등록 / 등록 전(곧 시작) / 종료 예정 | 등록 중 수 · 이번 달 새 등록·종료 |
| 과목 | 교재 없는 과목 / 학년 빈칸 | 영역별 과목 수 |
| 라이브러리 | 가격 없음 / 단원 없음 / 과목 없음 / 표지 없음 | 사용 중 권수 · 많이 쓰는 책 3권 |
| 진도관리 | 다음 교재 대기(시작 필요) / 진행도 100%인데 진행 중(수료 필요) / 최근 2주 기록 없음 | 진행 중 수 · 평균 진행도 |
| 교재비 | 보내기 전 / 미납 | 이번 달 청구·받은 금액 |
| 수강료 | 보내기 전 / 미납 / 과오납 / 이번 달 아직 생성 안 한 등록 | 이번 달 청구·받은 금액·미납률 |
| 비용 | 결제 수단 빈칸 / 금액 0 | 이번 달 지출 합계 · 큰 지출 3건 |
| 청구 항목 | 미납 / 종류 빈칸 / 기타경비인데 항목 빈칸 | 종류별 합계(교습비 · 기타경비 · 그 밖) |
| 손익 분석 | — | 이번 달 손익 · 지난달과 차이 |
| 법정 서류 | 신고 과정명 없는 클래스 / 도장 없음 | 이번 달 영수증 건수 · 인쇄 안내 |
| 알림톡 설정 | 꺼져 있는 종류 / 템플릿 심사 중·반려 | 켜진 종류 수 |

창이 없는 네 화면(오늘 · 수업 · 학원 정보 · 관리자 설정)은 그대로 둔다. 오늘은 화면 자체가 할 일 요약이고, 수업은 블록을 누르면 창이 열리며, 설정 두 화면은 카드로 다 보인다.

## 다. 만드는 순서(안)

1. 공용 부품: [할 일] 창(탭 + 줄 + 빈 상태 요약)을 학생·시간표의 것에서 뽑아 표 화면이 `L.todo=[{k,name,rows(),why,act}]`만 정하면 나오게 한다.
2. 돈과 직접 걸린 화면부터: 수강료 · 교재비 · 청구 항목 · 진도관리 · 등록 · 클래스.
3. 나머지 화면.
4. 왼쪽 메뉴의 숫자 배지(지금 학생·수업·등록에만 있음)를 같은 할 일 수로 맞춘다.

## 라. 확인이 필요한 것

- 할 일 기준 가운데 노션 매뉴얼에 근거가 있는 것과 내가 정한 것이 섞여 있다. 화면별로 매뉴얼 절을 대조해 표시해야 한다(아직 안 함).
- 할 일 창과 위 줄 거르기 알약이 같은 조건을 두 번 보여 주게 된다. 알약을 줄일지는 대표 결정.

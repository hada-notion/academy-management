# 관리 앱 시제품 (prototype)

노션에서 하던 학원 업무를 한 화면에서 다루는 "관리 앱"의 눌러 볼 수 있는 시제품이다.

- **예시 데이터만** 들어 있고 서버·노션과 연결되어 있지 않다. 저장·전송은 화면 표시만 바뀐다.
- 운영 화면이 아니다. Pages에 배포하는 화면 목록(`tests/design-lint.cjs`의 `PAGES`)에 들어 있지 않다.
- 여는 법: 저장소 루트에서 정적 서버를 띄우고 `prototype/admin-app/hada-admin.html`을 연다(엑셀 받기는 `vendor/exceljs-4.4.0.min.js`를 쓴다).

| 파일 | 내용 |
|-|-|
| `hada-admin.html` · `app.css` | 앱 본체(한 파일)와 화면 스타일 |
| `pick.js` · `pick.css` | 고르기 모듈(학생·클래스 목록, 카드) |
| `field.js` · `field.css` | 입력칸 모듈 |
| `hada-tokens.css` | `assets/hada-tokens.css` 사본 |
| `관리앱-기준.md` | 화면 기준: 영역·부품·크기·공통 규칙·예외 |
| `관리앱-화면명세.md` | 화면별 동작. 8장(표 화면 정의)은 코드에서 뽑아 만든다 |
| `서버-설계.md` | 실제 연결 설계(복사본 테이블 · `app-api` · 배포 순서) — 아직 만들지 않음 |
